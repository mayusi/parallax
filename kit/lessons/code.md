# Lessons — gameplay code, networking, data

- 2026-10-04 (mayusi, Parallax): Every OnServerEvent/OnServerInvoke argument goes through Guard and the handler through RateLimit — kit audit fails the build otherwise.
- 2026-10-04 (mayusi, sample_game): Lune headless specs have no Vector3 global (typeof(Vector3) is nil), so shared Rules must take plain {X,Y,Z} shapes that real Vector3s satisfy in game; enforce the real engine type server-side with Guard.vector3 before the Rules.
- 2026-10-04 (mayusi, sample_game): Camera zoom limits are Player properties (CameraMinZoomDistance / CameraMode = LockFirstPerson), not Camera ones — setting camera.MinZoomDistance errors and kills the whole LocalScript. Re-read Workspace.CurrentCamera; it is replaced on respawn.
- 2026-10-04 (mayusi, sample_game): A tool the server auto-equips goes straight into the character, never the Backpack: client code (and playtests) must look for it in BOTH places or nothing gets hooked.
- 2026-10-04 (mayusi, sample_game): Flinging/pushing unanchored parts from the server: call part:SetNetworkOwner(nil) first — parts near a player are simulated by that client, which silently overwrites a server-set AssemblyLinearVelocity. Hand back with SetNetworkOwnershipAuto later.
- 2026-10-04 (mayusi, sample_game): First-person weapons: never move the welded tool per frame (it trails the camera by a frame and rebuilds the weld 60x/s = stutter). Render a client-only copy under the camera in BindToRenderStep(Camera+1), drawn at ~0.3 scale and 0.3 distance (no wall clipping), hide the real handle with LocalTransparencyModifier, and make the real Handle Massless + CanCollide false. Keep it RIGID (camera.CFrame * offset): sway driven by per-frame camera/mouse deltas shakes because mouse input arrives unevenly — the owner called it choppy.
- 2026-10-10 (mayusi, Parallax): Patching repo files from Python on Windows: open(p, "w").write(s) turns LF files into CRLF (text mode); .luau files are eol=lf, so stylua --check fails kit verify on EVERY line while git diff looks clean (autocrlf hides it). Read and write bytes (open(p, "rb") / "wb"), check with git ls-files --eol. And a Python patch script written through a bash heredoc can lose a backslash level (a doubled backslash arrives single): write patch scripts with the editor tool, assert every old text is present before replacing.
- 2026-10-13 (mayusi, Parallax): Selene's last two lines are 'N warnings' and 'N parse errors' — the error COUNT is the line before. Checking 'tail -2' hid two if_same_then_else errors that failed kit verify in a fresh install; grep for 'errors' instead.
- 2026-10-17 (mayusi, Parallax): Baseline 2026-10-16: kit fuzz 747 hostile calls over 7 modules, 0 crashes; kit mutate 52/54 planted bugs caught (96 %, the bar is 80 %). A drop in either is a regression to explain in the handoff, not noise.
- 2026-10-17 (mayusi, Parallax): Playtests in .verify on 2026-10-16 are partial (anim_root_motion 3/9, moves_hitstop 7/12, owner_character_actions 8/14 checks): specs and fuzz green do not mean the engine agrees - a system is done only when its playtest scenarios pass in Studio with a clean console.
