# Lessons — the kit itself, harnesses, workflow

- 2026-10-04 (mayusi, Parallax): Never pipe a gate into tail/head when the exit code matters (it hides the failure). Check the real exit code before committing.
- 2026-10-04 (mayusi, sample_game): VERIFY-BLOCKER: serde pretty-vs-compact float instability makes ui/world drift checks ALWAYS stale once models contain non-exact-binary floats. Proof: ScopeOverlay accent 231/255 encodes ...764 in the written file vs ...765 fresh; OrbitalRange ring pos 28.0737202661892 vs ...202. kit ui/kit world write pretty (encode json, true) but verify compares compact encodings, so 1-ulp diffs fail forever. Until kit normalizes (write compact, or tolerance compare), verify can never go green on real content. Do NOT edit kit/ or generated files to fake it.
- 2026-10-04 (mayusi, Parallax): Open Cloud: FBX uploaded with assetType Mesh gives a MeshId that AssetService:CreateMeshPartAsync loads (verified in Studio); Animation uploads take .rbxm (kit upload exports them from the built place); new Image/Audio stay Pending in moderation for a while; private audio only plays in experiences it is granted to (kit upload grants to upload.universe).
- 2026-10-04 (mayusi, Parallax): wally install deletes/recreates Packages/ and crashes a running rojo serve (Studio silently stops syncing). After kit add, restart rojo serve; kit update no longer runs wally when packages exist.
- 2026-10-04 (mayusi, Parallax): When patching files with string replacement, ASSERT the old text is present — the formatter reflows long calls, and an unasserted replace silently does nothing (the viewmodel arms kept their old size for a whole test round).
- 2026-10-06 (mayusi, Parallax): Vetting an install: read a package's pyproject.toml dependencies as well as setup.py — FlexGEMM's setup.py lists only torch, its pyproject pulls triton-windows on Windows (caught after the download; the owner approved keeping it). And check every component's licence, not just the headline model's: TRELLIS.2 is MIT, but its default helpers nvdiffrast (NVIDIA, non-commercial) and RMBG-2.0 (CC BY-NC) are not.
- 2026-10-06 (mayusi, Parallax): kit trace stores side/top outlines back to front (u = 0 the back) whichever side the picture had the front on — trace.py turns them. Never turn them again downstream (kit refs views did, so its stations and part positions came out from the wrong end; fixed 2026-10-06 with its test).
- 2026-10-06 (mayusi, Parallax): Vetting a MODEL: the approved file list can miss what its code fetches at run time. Grep its configs for from_pretrained names and list the main weight file's state-dict keys (torch.load(mmap=True, weights_only=True): seconds, no RAM) BEFORE calling it installed — Hunyuan3D-Omni's 12 GB DiT file holds no image or control encoder (752 keys: t_embedder, x_embedder, blocks, final_layer); it also needs cond_encoder/pytorch_model.bin + facebook/dinov2-large
- 2026-10-06 (mayusi, Parallax): pip download --no-binary of an sdist already RUNS its setup.py (the metadata step) before you can read it — vet sdists by fetching the file by URL, checking its PyPI sha256 and reading setup.py/pyproject first (natten 0.21.7, 2026-10-06).
- 2026-10-10 (mayusi, Parallax): Lune's fs reads yield, and Luau forbids yielding inside a metamethod: a lazy __index loader that reads a file returns nil silently (pcall swallows the yield error). Load eagerly at module load instead.
- 2026-10-10 (mayusi, Parallax): A kit step whose tool prints a huge JSON result line (~13 KB: fxlab listing 184 renders) fails with an EMPTY summary — keep result lines small (only what changed + counts).
- 2026-10-13 (mayusi, Parallax): Python modules of different lanes share names (check.py, library.py, look.py): the combined test run (kit/test/python/run.py) imports whichever loaded first and 8 tests errored in a fresh install. Give new modules unique names (sfxlib, worldcheck, worldlook) or load by path with importlib under a unique name.
- 2026-10-13 (mayusi, Parallax): A server a kit command starts (a local booth) dies when the command returns: Lune runs tools inside a Windows job that is killed on exit and forbids breakaway. Start it through WMI (Invoke-CimMethod Win32_Process Create) so it lives outside the job. And bind a per-launch token + Host/Origin checks: any web page can POST to 127.0.0.1.
- 2026-10-16 (mayusi, Parallax): Parallel sessions in ONE checkout: repo-wide kit verify can only be green at a moment when no session has half-edited Luau on disk (stylua --check runs on every file; the format step fails on another lane's work in progress). Verify your own slices with the lane's commands (stylua + selene on your files, the specs, python tests) and journal milestones only at those moments; a red gate that belongs to another lane is recorded, never fixed from outside it.
- 2026-10-16 (mayusi, Parallax): kit status counted every .verify/<name>.json with a gate prefix as a gate: 103 old per-asset / optimize / judge verdicts (tournament candidates, probes) made 48 failing gates out of 5 real ones. A per-item verdict is a REPORT below its bar (the bar is the owner's); pipeline gates have no item in their name. kit vault prune-verdicts retires files whose input is gone or whose run was a usage error (.verify/retired/ + REASONS.txt).
- 2026-10-16 (mayusi, Parallax): The python unit tests must run ONE FILE PER INTERPRETER (kit/test/python/run.py): the lanes' modules share names (plan.py, judge.py, trace.py, library.py, find.py, fit.py, measure.py, preview.py, refs.py, silhouette.py, vault.py) and each test puts its lane's folder first on sys.path, so one process imports whichever loaded first. Isolated: 118 files, 1,072 tests, ~15 min on this machine; a crash before unittest's summary counts as one error with the tail printed.
- 2026-10-16 (mayusi, Parallax): Lune's serde YAML round-trips plain frontmatter (quoted strings with escaped quotes, flow lists); write the YAML by hand in a fixed key order so notes diff cleanly, parse with serde.decode('yaml'); a link to a FOLDER ([[3d/lessons|folder]]) must resolve by fs.isDir or the health check cries wolf; a note's body starts after ONE blank line (strip the leading newline or every lesson line ends with a space and never dedupes against the old one-line files).
- 2026-10-16 (mayusi, Parallax): A Luau function returning two values, called in the middle of a table constructor, is truncated to its FIRST value (the doctor's department rows got a string where the args table should be: 'invalid argument #1 to concat'). Return one table, or put the call last.
- 2026-10-16 (mayusi, Parallax): stylua reflows a long table row onto several lines, so a python patch written against the one-line form misses silently: assert the count of every replacement. The Edit tool is the safe route for Luau or Python that holds backslashes - a Bash heredoc eats them.
- 2026-10-16 (mayusi, Parallax): A test runner built on unittest collects NOTHING from pytest-style files (top-level def test_, no TestCase) and reports 'Ran 0 tests' as green: 12 anim files / 84 tests never ran inside kit verify. Count the tests a gate runs per file; a file with def test_ and a zero count is a hole, not a pass. The runner now routes such files through pytest.
- 2026-10-16 (mayusi, Parallax): Proving the COMMITTED tree while other sessions hold half-edited files in the same checkout: git worktree add --detach ../<repo>-verify HEAD, junction build/ DevPackages/ Packages/ ServerPackages/ into it, recreate the games' empty asset folders (git keeps no empty dirs), copy games/.active, then run kit verify there. A format diff that shows up THERE is a file committed unformatted.
- 2026-10-16 (mayusi, Parallax): Two verify gates fail on a FRESH checkout but never on the owner's: tests that read a git-ignored data folder (_artifacts/r6data) and a bake whose derived steps run before the phase that writes what they read (kit anim's rearm before the R6 fold). Prove HEAD in a sandbox worktree with an EMPTY build/animations once in a while; a gate that is green only on one disk is not green.
- 2026-10-16 (mayusi, Parallax): `kit upload --help` is NOT a help flag — it starts a REAL full upload (every lane's queue). Always use `kit upload --dry-run --only <text>` then `kit upload --only <text>`
- 2026-10-17 (mayusi, Parallax): A subcommand must never write its department's gate record: kit ui plan/judge/... wrote .verify/ui.json (the build gate), so kit status showed the UI gate red whenever a screen had stages left, and the plan then read its own report instead of the build notes. Per-item work reports under <dept>-<sub>.json (kit status treats a hyphenated name as a report, not a gate).
- 2026-10-20 (mayusi, Parallax): A bare 'git clean -fd' (or 'git add -A' then 'git reset --hard') in a worktree whose shared folders are JUNCTIONS into the main checkout deletes the owner's real files through the link: on 2026-10-20 it emptied _downloads (6,150 files, 4 GB, restored from the E: copy). Every worktree script must exclude its linked folders by pathspec, dry-run first, and never git-add inside them; /_downloads/ is now in .gitignore.
- 2026-10-21 (mayusi, Parallax): Never call fs.metadata (or any Lune call that yields) inside a table.sort comparator: a comparator cannot yield, so wrapped in pcall every time silently reads as 0 and the sort keeps a random order. Read the times into a table BEFORE sorting (Vault.verdicts / Vault.pairs do).
- 2026-11-10 (mayusi, Parallax): Blender 5.2 starts with UV sync select ON: after picking faces, bpy.ops.uv.select_all(action='SELECT') selects the WHOLE MESH, so the next unwrap or pack runs on every face (the rim's laid strips and stacked copies were unwrapped again over their own UVs, the maps came out 15-40% used). Drive UV operators by the mesh's face selection: set tool_settings.use_uv_select_sync = True, select faces with bmesh (faces.index_update() first: an edit mesh's indices can be stale), select_flush_mode(), never uv.select_all; put the user's setting back after.
- 2026-11-10 (mayusi, Parallax): Chamfering a lathe low's sharp 90-degree corners (the mid-poly fix for wavy edge highlights) leaves no edge over the seam angle: the whole revolve becomes ONE closed region (topologically a torus), and an unwrap that sends closed regions to the smart projection drops the map from 78% to 25% used (the car rim's barrel, rework 6ebz). Open a closed region at its sharpest edge loops before classifying it (rbx_uvparts._open_closed), then cut it into strips as usual.
- 2026-11-10 (mayusi, Parallax): Identical parts stacked on ONE place in the UVs must also be cut into the SAME triangles: BEAUTY picks an n-gon's diagonals by shape and a turned copy's float noise flips its ties, so the copy's corners were laid from other islands (the car rim's Spoke2: 54 corners guessed, a striped blotch on one spoke, rework 6ebz, 2026-11-10). rbx_uvparts.triangulate_like cuts each copy along its original's diagonals and keep_copies checks every pair again on the triangles (facts copies_dropped). And make copies by turning ONE part (a.cad(..., rot=)), never by turning inside the CAD code: each angle is meshed and rounded its own way and only two of five spokes matched.
- 2026-11-11 (mayusi, Parallax): A selftest case's needle must be words only the REAL fault prints, never the check's own label or rule id. check_graveyard_rows.py's PASS line read 'graveyard (G9): no graveyard rule', so expectSpared with needle 'G9' always misfired (the full kit selftest stopped there for every lane, 2026-11-11) and expectFlag with 'G9' was hollow (caught with the rule silent). Before registering a case in kit/cmd/qa.luau, run the check on BOTH fixtures and see each needle in the bad summary and absent from the clean one.
- 2026-11-12 (mayusi, Parallax): A number that describes a picture is laid on the frames BEFORE it is trusted, and the page that shows it is built first. V0 (2026-11-12): the first timing read called the brightest frame 'the hit' - on a fire arc that is there in one frame and then creeps brighter for 0.7 s, that is frame 25 of 28, and the read said 'lead-in 0.63 s' where the frames show a one-frame snap. The unit tests passed (made discs peak when they arrive); one look at the first dailies page showed it. Same look, two more: a pad round our beat let the next beat's flash in, and an upload's doubled frame was called a freeze. So: make the look-at page the first thing a measuring tool produces, run it on one real clip, and write the test from what the real clip broke.
- 2026-11-12 (mayusi, Parallax): Roblox Studio's Assistant context (what the Studio MCP's execute_luau runs in) cannot call a local server any more: HttpService:GetAsync answers 'HttpService request denied: domain 127.0.0.1:<port> is not in the Assistant HTTP allowlist' for every local port tried on 2026-11-12 (47811, 47812, 47823, by 127.0.0.1 and by localhost), and it cannot read Lighting.Technology ('lacking capability RobloxScript'). So a capture server a Studio script calls back (kit vfx booth, kit ui booth: /grab from HttpService) gets no call. What works: the script signals by what is ON SCREEN and the kit reads the window - kit world studio covers the 3D view with a plain colour from a CoreGui ScreenGui (magenta = start, yellow = next station, cyan = over; CoreGui parenting is allowed) and kit/world/studio_shots.py reads the place's own window with PrintWindow a few times a second, which also tells it where the 3D view is. A second Studio opened on a local .rbxlx (RobloxStudioBeta.exe "<file>") registers with the MCP as its own studio_id within about 30 s.
- 2026-11-12 (mayusi, Parallax): Never name a kit flag --list: Cli.parse keeps repeated flags in flags.list (always a table), so 'if flags.list' is true on every call, and a bare --list REPLACES that table with true (the next --key value flag then crashes). kit review's first build printed its text listing instead of serving the page for exactly this reason (2026-11-12); it is --stages now. Compare a boolean flag with == true, and pick a name that is not a field the parser owns.
- 2026-11-12 (mayusi, Parallax): In a checkout several sessions write to, a file is looked at AT the commit, not minutes before: f494f468 added kit/cmd/qa.luau whole a moment after another session had put ten lines of its own there, and kit selftest crashed on the committed tree (a call to a function that session had not committed). The dry run's line count said 29 where I expected 19 and I did not read it. So: for every modified file print its hunk count in the dry run and READ it; stage a file another session may touch through its own hunks (git apply --cached of a filtered patch), never whole; and commit only the tree the dry run showed (write the tree's hash down in the check, compare in the commit). And run the gate self-test on the committed tree after every kit commit: this was found only there.
- 2026-11-12 (mayusi, Parallax): An owner approval must be bound to what he LOOKED AT, not to what it was made from. V1's style sheet was approved by an id hashed from the preset, the set and the chart's plan: the same preset recorded again (a texture changed, the preset's file did not) and drawn again kept the id, and the old yes read 'approved' for pictures he never saw. Bind three things: the artefact names its pictures (a hash read from the picture files at every check, never from its own record); the record keeps that hash and ONE comparison is shared by the lock and the page (LaneLocks.holds); the click names what the page showed and the command is told it too (--expect) and reads the artefact once more itself. A second fresh review found it: the first review's fix was only half of it.
- 2026-11-12 (mayusi, Parallax): A guard that says 'this path must not be that file' cannot be written as a comparison of spellings: one file has many (./x, X, the absolute path, and on Windows a trailing dot or space, an 8.3 short name, a ::$DATA stream). Say where the path MUST be instead (a test fixture's locks file: a plainly spelled file under build/) and refuse everything else (Locks.useFixture).
- 2026-11-12 (mayusi, Parallax): A page the kit serves on 127.0.0.1 that takes WRITES must forbid being framed. A token only the page knows, an exact Host and a same-origin check all pass for a page shown inside another site's frame - its requests are its own - so a site the owner has open could lay it invisibly over its own buttons and turn his typing and his click into an approval of something he cannot see. Two lines close it (Content-Security-Policy frame-ancestors 'none' and X-Frame-Options DENY: LocalPage.pageHeaders), plus refusing a request whose Sec-Fetch-Dest is a frame. Found by the third fresh review of kit review, not by the first two.
- 2026-11-12 (mayusi, Parallax): A review's fixes are reviewed again, and the rounds have a stop rule. kit review's first review found 15 defects, the review of those fixes found five of them half-fixed plus one serious new one (a yes bound to the preset, not to the pictures), the review of THOSE fixes found three middling ones and nothing serious. So: a round that finds nothing serious closes the cycle - its smaller findings are fixed with tests and not reviewed again; a round that finds something serious is followed by another. And every defect of all three rounds sat in a path no test walked end to end: write the end-to-end test of the path BEFORE the first review, it is cheaper than a round.
- 2026-11-12 (mayusi, Parallax): A tool that makes something reads its own output back against its plan before it calls it made. kit vfx animatic records its flat shapes and then measures where each beat's light arrives and how much of the frame it covers: its first run failed its own check four times in ten minutes, and each failure was a real fault - a colour the read did not see, shapes cut by the booth's ground, and a clock fault in the two sprints BEFORE it (recordings read by the chart's time instead of their own real time). No review had found that one.
- 2026-11-12 (mayusi, Parallax): A check's tolerance can hide a wrong MODEL. The timing animatic's own check allowed 1.5 frames between where its plan put a hit and where its recording showed it; the clock model behind it (a sum of the hit-stops) was itself up to a frame and a half off, so a real two-frame error on two beats passed for hours. Made exact (the recorder's loop, frame by frame, held to the times a REAL recording posted), the error stood out at once and its cause was real: the hit lay between two drawings. Before you trust a tolerance, hold the model to one real output of the real tool (a golden test, never numbers made by the same formula), then look at what the tolerance was hiding.
- 2026-11-12 (mayusi, Parallax): After a review's fixes, run the REAL path once and read its numbers before calling the round done. A fixture made from the plan agrees with the plan by construction: the fixed animatic tool passed every made test, and its first real run (the real recorder, the real built effect) showed four faults the review had not found - two beats two frames late, a read that called a beat's own first drawings its floor, early beats never named, the next beat's light read as this beat arriving late. Each was in code the tests covered.
- 2026-11-12 (mayusi, Parallax): lune (like every rokit / aftman tool) is found through the PROJECT's tool manifest. Started from a folder outside the project - a made project in a temp folder, as the Python tests use - it fails with 'Failed to find tool lune in any project manifest file' and prints nothing on stdout. A Python tool that calls a Luau helper must start it with cwd = the folder kit/ is in and give it absolute paths (kit/vfx/animatic.py refusals()).
- 2026-11-12 (mayusi, Parallax): A check's allowance must come from what was APPROVED, never from the piece under test. The drift check (a built effect held to its timing animatic) gave a light that 'takes its time' a quarter of its own arrival on top of one drawing: a spark at the beat's start made the effect's arrival three frames long, and that bought a snap three frames late - the very case the gate says is named. If the measured thing can widen its own tolerance, it will. And when a tolerance seems too strict on a real piece, look at how the piece is READ before loosening the rule: the real fault was the read (it timed the run that holds the brightest frame, not the first arrival).
- 2026-11-12 (mayusi, Parallax): A tool removes its old output only when the replacement is certain. kit vfx animatic removed the set's record and video 'first, so nothing stale is left', and only then checked whether it could make new ones: asked to read a recording that was not there (another view), it left the set without the animatic the owner may have approved. Do every refusal first; remove at the last moment before writing; and let what stays READ as out of date (an id that no longer matches) instead of deleting it.
- 2026-11-12 (mayusi, Parallax): When each review of a fix round finds its serious faults in what THAT round added, stop adding. Three reviews of the timing animatic's fixes each found holes in the newest rule (an allowance for slow arrivals, a special floor for our recordings, a layer started 'a thousandth early', a bundle looked up by name). The round that held took them OUT: one rule instead of two, the exact sum the player itself computes instead of a safety margin, and a third answer - 'not read' - where the checker cannot tell, instead of a cleverer guess. Before the next fix, list what the last round added and ask of each: can the fault be removed by removing this?
- 2026-11-12 (mayusi, Parallax): A number in a comment, a test name or a lesson is a claim: run it before writing it. '2.025 - 1.9 is a hair under 0.125 in a computer' went into a code comment, a test and a recorded lesson - and it is false (it is exactly 0.125). The real case was found only when a test pinned a value that did not come out: 0.175 - 0.05 is 0.12499999999999999. Any example of float behaviour, any 'N of M', any measured figure: paste it from a run, never from memory of what it should be.
- 2026-11-12 (mayusi, Parallax): A platform limit is two numbers - what its maker SAYS and what you have SEEN arrive through your own route: keep them as two constants (rbx_optimize.ROBLOX_MAX_TEX 4096 said, GAME_MAP_CAP 1024 seen) and let only the test move the second. - 2026-11-12 (mayusi, Parallax): Before building a rule, grep which route REAL pieces take: H3's map-by-need was written for game-stage hero builds and proven on a fixture of that kind - and every one of the nine hero scripts and kit make write MASTERS, so it would never have run. The fresh review found it by grepping stage= in the real scripts; I had only counted them.
- 2026-11-12 (mayusi, Parallax): A fact computed in a step that a cache skips vanishes on the cached run (the packing fact is made during the unwrap; a bake-cache hit skips the unwrap): store it in the cache's own record, and build the fixture TWICE (fresh, then from the cache) before trusting a self-test needle that reads it - the second self-test run would have missed its case.
- 2026-11-12 (mayusi, Parallax): Prove a change to the bake by baking the SAME fixtures with the committed builder and the working one and comparing the maps texel by texel (swap the file in a script with a trap that always puts it back; never two at once): it showed in a minute that the first approach changed 1% of the texels, before any review. - 2026-11-12 (mayusi, Parallax): Measure a claim with the very CALL the product makes: 'never under Blender's packer' was measured with pack_best(at_least=None), while the builder passes at_least = the box cover x 1.005 - a different start for a search that is not monotonic, and the real call lost on one set. - 2026-11-13 (mayusi, Parallax): Write a run's result into a card only by quoting its own summary line after it ended.
