Roblox Beam textures run the image's VERTICAL axis along the beam (Attachment0 -> Attachment1) and its horizontal axis across the width (measured in Studio 2026-10-10: a horizontal strip gave a flat, hard-edged slab). Author beam strips upright (kit/vfx/fxfinish.py "beam": true turns a lengthwise render upright); TextureLength / TextureSpeed act along the vertical axis.
