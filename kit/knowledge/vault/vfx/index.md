# VFX — the department's page

**The route:** breakdown (the source's REAL frames - an anime scene, or real footage of the phenomenon for an
original - + its text + a timed beat sheet with measured colours) -> chart (ONE test frame the owner approves) ->
textures (Blender recipes, GPU sims) -> preset (v3 layers) -> play (the browser player: the effect alone, where it is
judged; Studio is off the route) -> the OWNER's number -> ship (library/vfx; promote on >= 7).

**The owner's rules:** the source's own look at anime / AAA quality, never a genre swap or the last success's look; the
hybrid (meshes + flipbook cards) is the base; impact frames only over a strike on screen; smoke is one simulated event;
metric wins are not the bar.
