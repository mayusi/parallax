# Verdict inbox

Write your verdicts here in Obsidian, one line each under **New**: `- <kind> <name> <score> <your words>`.
Kinds: asset, vfx, ui, sound, world, anim, system, playtest, kit. Scores 0-10 or 0-100. Put quotes around a
name with spaces. The next `lune run kit vault sync` (or `kit status`) files each line as a verdict note and
moves it to **Filed** with a link. A line it cannot read stays under New with a note saying why.
Three more kinds of line: `- rule <dept> <words>` (a standing order every session of that lane obeys),
`- never <dept> <words>` (a graveyard row: a route never to try again), `- retire <words of a lesson>` (that
lesson stops being shown; it must match exactly one lesson).
