A lock must tell 'made before the rule' from a COMMITTED list, never from whether a generated file exists: the first blocking lock called a move new when it had no built model, and 37 committed strike moves have no committed model (the models are untracked), so a fresh checkout and kit prove would have refused them all - and an empty hand-made model file freed any move. The rule is now a frozen list (assets/animations/blocks/_before_blocking.json), and an approval counts only when the record says it was the owner's, holds the poses he saw and carries their id (a one-line hand-typed record had freed a move). Ask of every lock: what does a fresh checkout see, and what is the cheapest file a session could write to pass it?
