A gate that is green on one disk is not green: kit prove (a sandbox worktree of the commit) found six bugs no session's own verify could see on 2026-10-16/17 - committed-unformatted files, a test reading git-ignored _artifacts data, kit anim's re-arm-before-fold build order, an uncommitted asset-id registry, CRLF from a fresh checkout breaking byte hashes, and an empty mesh cache changing a preview. Prove the committed tree (lune run kit prove --selftest) before calling a lane done.
