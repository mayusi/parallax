Compare TEXT by content, never raw bytes: git on Windows (core.autocrlf) writes CRLF into a fresh worktree while the kit's tools write LF, so a byte hash called 83 unchanged UI screens stale. Hash text with CRLF read as LF and accept either form from older manifests (kit/ui/vault.py same()).
