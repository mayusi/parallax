# Sound — the department's page

**The truths:** the model cannot hear (numbers against a reference are the only evidence it can read); real
recordings beat synthesis (the synth-only sword set was "middling": booth 6 -> 5, 5 -> 4); a sound is never alone
(judge in sync with the hit's animation and effect, in the engine); a game has a sonic identity.

**The route:** refs (up to three reference recordings per class chosen by the OWNER in booth rounds; the Creator
Store's licensed audio first, then Freesound CC0 / Kenney / Sonniss) -> identity (measured from the references) ->
design (layers with ROLES, real sample layers, a SET with one DNA + weights + one loudness per class) -> match (one
difference + one edit per role, never a score) -> sheet (looked at beside the reference) -> booth (the owner scores
1-10; the taste profile predicts only after the owner) -> av (the sound on the SampleDojo's capture at the Hit; an A/V
offset gate) -> runtime (events; `Sfx.play` / `broadcast` proven by a playtest) -> upload (moderation, grants).
