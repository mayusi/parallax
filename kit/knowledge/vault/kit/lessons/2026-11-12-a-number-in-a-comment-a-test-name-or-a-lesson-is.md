A number in a comment, a test name or a lesson is a claim: run it before writing it. '2.025 - 1.9 is a hair under 0.125 in a computer' went into a code comment, a test and a recorded lesson - and it is false (it is exactly 0.125). The real case was found only when a test pinned a value that did not come out: 0.175 - 0.05 is 0.12499999999999999. Any example of float behaviour, any 'N of M', any measured figure: paste it from a run, never from memory of what it should be.
