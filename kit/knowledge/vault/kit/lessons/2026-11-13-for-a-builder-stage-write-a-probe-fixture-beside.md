For a builder stage, write a PROBE fixture beside the positive one: a script that makes plain parts, calls the new calls, builds nothing and prints one json line of measured places and volumes (check_deform_cases.py, check_strew_cases.py, check_repeat_cases.py). It runs in seconds, so every fault a review finds gets its own case and test the same hour, and three stages could be reviewed and fixed in one sitting
