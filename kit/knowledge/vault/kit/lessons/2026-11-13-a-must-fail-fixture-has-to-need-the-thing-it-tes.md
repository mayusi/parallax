A must-fail fixture has to NEED the thing it tests: take the feature out (a scratch copy with the option deleted, or the code path mutated) and see that the expected words are no longer printed. My slanted-lane fixture failed with the same 'w 6.0' with every turn deleted, because its walls were 6 apart on an axis too: it could not catch a compiler that stopped turning. Typing the claim at the angle and turning only the walls made a broken turn read another number
