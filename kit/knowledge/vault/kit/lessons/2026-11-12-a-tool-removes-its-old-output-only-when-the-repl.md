A tool removes its old output only when the replacement is certain. kit vfx animatic removed the set's record and video 'first, so nothing stale is left', and only then checked whether it could make new ones: asked to read a recording that was not there (another view), it left the set without the animatic the owner may have approved. Do every refusal first; remove at the last moment before writing; and let what stays READ as out of date (an id that no longer matches) instead of deleting it.
