A measurement off a picture is not proven on drawn rectangles on a plain ground: that is the one case where every method works. Before calling it proven, run it READ-ONLY on the project's real reference pictures (gather + measure, nothing written: _scratch/colour/real_probe.py) and print how the object was found and how much of the border it took. My colour plan passed 22 tests and measured the BACKGROUND on real photos (84-90% of the border as 'object'); a fresh reviewer found it by trying real pictures. And a change to a page someone approves must still SHOW everything that approval's id covers.
