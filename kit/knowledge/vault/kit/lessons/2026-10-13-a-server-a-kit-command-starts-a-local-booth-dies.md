A server a kit command starts (a local booth) dies when the command returns: Lune runs tools inside a Windows job that is killed on exit and forbids breakaway. Start it through WMI (Invoke-CimMethod Win32_Process Create) so it lives outside the job. And bind a per-launch token + Host/Origin checks: any web page can POST to 127.0.0.1.
