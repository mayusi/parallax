When a stage adds an ORDERED list (layers, stages, passes), test taking out the FIRST item, not the last: my layers' noise was seeded by list position and the only removal test removed the last one, so every other layer moved unseen. And prove a 'nothing is baked again' claim on a fixture WITHOUT the feature that happens to make it true (mine already had wear numbers, which baked the pass the claim denied). A fresh reviewer found both in ten minutes.
