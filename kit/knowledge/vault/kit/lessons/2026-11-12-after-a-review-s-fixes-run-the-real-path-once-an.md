After a review's fixes, run the REAL path once and read its numbers before calling the round done. A fixture made from the plan agrees with the plan by construction: the fixed animatic tool passed every made test, and its first real run (the real recorder, the real built effect) showed four faults the review had not found - two beats two frames late, a read that called a beat's own first drawings its floor, early beats never named, the next beat's light read as this beat arriving late. Each was in code the tests covered.
