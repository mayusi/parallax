# 3D — routes per part family (what worked, what is forbidden)

The route a part is made by is decided in the brief's parts plan (`- parts plan:` — `<part> | <shape modules> |
<data> | <surface>`) BEFORE any reference is gathered. `kit plan <asset>` prints each part's route and refuses a line
that matches a graveyard rule below. Links: [[3d/graveyard]] (the owner-facing record), [[3d/golden]], [[3d/index]].

## Graveyard rules (enforced by kit plan)

Every row is a route that failed on the record, with the owner's words and why it is not retried. A parts-plan line
that matches a row is REFUSED unless that line quotes the owner allowing it: `... | owner: "<their words>"`.
Matching (case-insensitive): `tiers` = the asset's tier (the brief's quality, else the script's; `*` any); `part` =
a regex on the part's NAME only (`*` any);
`routes` = the line's shape routes exactly, alternatives split by `\|` (`code`, `generated+projected`, `*` any);
`text` = a regex the line must contain; `unless` = a regex that clears it (the method that fixed it). Add a row the
same turn an owner verdict rejects a route; never delete one — a route that later works gets a golden row.
