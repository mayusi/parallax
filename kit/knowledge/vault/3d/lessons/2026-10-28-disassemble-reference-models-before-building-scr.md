Disassemble reference models before building (_scratch/the_world/disassemble.py: every piece alone in 3 views + construction metrics + exploded views; teardown_report.py finds shared template pieces). InspWinship's R6 stands share one skeleton: each limb = cap / upper core / band / lower core / forearm shell / separate flat END SLAB (the hand or foot), cores split at elbow/knee (bevelled Studio-part boxes), armour = open smooth sculpt shells 0.03-0.10 proud, muscles = bow-tie capsule pairs, straps = ribbed oval loops, hearts = cut gems. 238 shapes are reused across his models.
