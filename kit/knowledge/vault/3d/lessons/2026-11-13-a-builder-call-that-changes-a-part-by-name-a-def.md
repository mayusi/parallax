A builder call that changes a part BY NAME (a deform, a zone, box modelling) has three duties the first build of a.bend missed. Refuse a copy's name (Part~m1): the part's copies follow the part. Try the change on EVERY mesh it will touch before cutting any, so a refusal leaves the model as it was. And when the change starts or stops inside the part, slice the part there first: a taper from half way up a plain bar had no vertex to start at and tapered the whole bar
