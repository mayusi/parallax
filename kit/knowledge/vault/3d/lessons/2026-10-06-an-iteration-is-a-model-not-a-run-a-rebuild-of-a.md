An iteration is a MODEL, not a run: a rebuild of an unchanged script (only a parts answer, the review or the brief changed) keeps its iteration number (rbx_score.iteration_of). If a hero build fails for a non-model reason, fix that and rebuild: the review it asks for stays the same number.
