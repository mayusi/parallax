Owner-only acts are confirmed at a REAL terminal: Lune's stdio.prompt fails with 'not a terminal' in an agent's shell even with piped stdin, so kit grade and kit accept --lower can be started by a model (in the owner's terminal) but finished only by the owner's keystrokes. Once a floor is COMMITTED, the committed one holds — found case-insensitively and by name anywhere, through git run as the repository says (GIT_* dropped, no replace objects), failing closed when git cannot answer (no edit, deletion or breakage of the file moves it; a change of floor takes effect once committed; a floor never committed is only its file), and the one re-base without the owner is a build MADE by the floor's own script (the file Blender ran, sha recorded at build time) that is the floor's model (fingerprint: triangles, size). Trusting the working file in any form lost to an edit: removing components, restamping the measure, a NaN.
