For an ORGANIC hero, a checked reference MESH as sculpt clay beats code primitives by a mile: the skull built from ~150 primitives (its outline matched to 0.93) was judged 28 / 28.5 by two fresh judges — the face, teeth and joints read as a blockout; the same skull as s.add_part(<the CC BY reference, imported at its real size>) then aged in code (noise, chips, the bone look) has the real anatomy (outlines 0.99), meshes in 2 s instead of 23 min, raw 57.1. The owner's OK first (an adapted work: credit the author — a.design['credits']); a GLB with LODs holds several meshes: split it and take the detailed one.
