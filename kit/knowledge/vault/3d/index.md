# 3D models — the department's page

**The route** (one planned pass, never a rebuild loop; `lune run kit plan <asset>` locks the stages):
brief (tier = budget: prop 10 min, complex 30, hero 60) -> gather (dossier, pictures ≥ 2 px/mm per hero feature,
two reference MODELS checked for quality, patents, turntables; every traced part looked at) -> draft (generators
per PART, organic only) -> shape (CAD from mm profiles + sections vs a reference model; organic from a checked mesh
as clay) -> surface (looks with sources, engraved markings, a wear preset, dark finishes stepped) -> mechanism
(after the look passed the owner) -> judge (the verifier's diff + one edit; the OWNER's number) -> ship (game
version spawned in Studio; promote only on an owner verdict ≥ 7).

**The owner's rules:** budgets are hard; gates are not quality; references first PER PART then build FROM the data;
check reference models for quality, not only proportions; "DON'T LOOP WITH BS CAD"; look at the render after every
milestone; our own unapproved builds are not reuse material; private designs never committed or uploaded.

**What worked, every time:** measured data (sections against the NSW Gen5 model took the Glock to 85; a CC BY mesh
as clay took the skull from 28 to 75); the part alone through a generator into a sculpt; a value step between two
dark materials. **What never did:** an extruded profile for a hero; a whole-object generator; SDF primitives for an
organic form; a lit render projected as colour; detail added to move a score.
