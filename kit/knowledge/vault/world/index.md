# World — the department's page

**The rule:** ONE world pushed to impressive beside its references (SampleRegion); no new worlds until the owner asks.
"The main idea of the mission was to improve quality"; "the quality of the terrain is horrid"; real meshes (trees,
rocks, cliffs, buildings) are the jump.

**The route:** refs (≥ 6 real stills measured: horizon line, value structure, haze, palette, landmark placement ->
a world identity) -> terrain (real elevation refined by rivers / erosion / the painter; design anchors kept) ->
materials (MaterialVariants from the scans by painter role) -> meshes (vetted CC0 rocks / cliffs / trees; ≤ 10k
parts; no z-fighting) -> dressing (roads first) -> check (0 errors: reachability with the real jump arc, traps, spawn
fairness, camera, knockback room; look lint clean) -> look (eye-level from the stills' cameras, one difference + one
edit per station; the viewer is art direction, not proof) -> studio (walked through the MCP with 0 console errors;
the OWNER walks it).
