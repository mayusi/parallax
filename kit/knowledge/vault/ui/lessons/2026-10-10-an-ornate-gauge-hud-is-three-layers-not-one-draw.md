An ornate gauge HUD is three layers, not one drawing: a RENDERED plate (troughs, wells, caps — kit ui render 'gauge' item, which also writes the wells' pixel anchors), LIVE cells laid over the wells (slant plates tinted with the fill token, generated by kit ui gauge from a 12-line .gauge.json), and GENERATED ornament (emblem, pips via kit vision concept). Measure the rows on the reference sheet first (green-pixel scan: rows 412/204 px long at 760 px width -> cells, lengths, lean). A dark steel plate reads silver in a thumbnail because of its lit bevel rims — probe the PNG's pixels before 'fixing' the material.
