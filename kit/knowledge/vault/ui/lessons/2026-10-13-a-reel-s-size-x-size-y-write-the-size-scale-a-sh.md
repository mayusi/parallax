A reel's size_x / size_y write the Size SCALE (a share of the parent), never pixels: size a fill's clip as a percentage ('91.3%') and key it in shares (694/760). Keys in pixels made the clips hundreds of times their parent, so a health drop never showed (StriveCombo, 2026-10-14). The ghost = a second clip under the fill, keyed later.
