A 3D render is the wrong SOURCE for a Persona-type figure however it is filtered (halftone ink = scribble, cel-mono = splat): the owner called every version horrible. Official 2D key art (kit ui refs <identity> ... --wiki <game> → a drawn full-body piece with its own lines) through kit ui ink --mode cel --palette mono reads as an illustration at once. Source quality is the ceiling: pick a DRAWN picture, then ink it.
