imageAlpha on an image / plate node is TRANSPARENCY (0 = opaque, 1 = invisible): a 'faint' crest set to 0.12 was 88 percent opaque and a judge called it 'full brightness colliding with the menu'. For a faint backdrop use 0.8-0.9; for a halftone wash 0.5-0.65. Check the compiled model's ImageTransparency when a backdrop looks louder than intended.
