When the owner says a screen 'looks bad', the answer is more REAL references of that exact screen type, not more polish: the first Arcade5 title was a Persona-flavoured collage; measuring the actual P5 title still (field 35% lower-left, edge falling right, logo over the edge, character huge, menu as a diagonal staircase on the black side, selected on a big splash) gave the structure in one rebuild. Fetch references through APIs when the page is gated (the Steam store appdetails API gives screenshots without the age gate; the MediaWiki API gives a File's real URL); never bypass a bot check.
