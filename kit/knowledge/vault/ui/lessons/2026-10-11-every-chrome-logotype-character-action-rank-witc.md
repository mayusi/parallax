Every chrome logotype (character-action rank, WITCH TIME, rank S, UMBRA) carried a mid-grey slab behind it that three judge pairs called 'a grey card / WordArt plate': the renderer's OUTLINE shell was a 0.6-metallic material reflecting the key light. An outline is ink: base 0, metallic 0, roughness 1, specular 0 (fixed in kit/ui/render.py outline_material). When judges repeat a complaint the designer 'does not see', measure the art: 70k opaque mid-grey pixels in the logo PNG said it before the judges did.
