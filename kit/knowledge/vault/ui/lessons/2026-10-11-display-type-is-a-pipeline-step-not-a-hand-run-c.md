Display type is a pipeline step, not a hand-run command: write text with "lettering" (true or overrides) and the kit ui words step bakes art:<identity>/w_<slug> from the identity's "lettering" defaults, re-baking only when a recipe changes (the round the owner rated 'genuinely amazed' converted to this was pixel-identical). Baked words keep their desktop pixels: give each group one at.phone/tablet scale (it shrinks the node and its children) and LOOK at phone + tablet — the first lettered build collided on both screens and only the promote gate (no look, no promote) caught it.
