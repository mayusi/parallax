# UI — the department's page

**The hero route** (`lune run kit ui plan <Screen>` is this as a stage board): refs (≥ 2 real stills of the exact
screen type at ≥ 1080p, measured at 1:1 into REFS.md; a gallery sheet is NOT a reference) -> identity (tokens
sampled from the stills by script, a font trio, shape language, motion, bans, minimums, lettering defaults) ->
pieces (rendered / traced / inked / lettered / spun — never a font glyph with a tint) -> assemble (from anchors;
crest_width sets the scale; children follow a warped parent) -> look (the sheet at phone / tablet / desktop + the
reel, numbers sampled; no look, no judge) -> judge (two fresh judges for BUGS; the OWNER's eye outranks the median
by 30-45 points) -> promote (library/ui; uploaded; promote on ≥ 7 with its data).

**The owner's taste:** real sources beat generated ones (a 3D render through any filter is a splat; official 2D key
art through `kit ui ink --mode cel` reads at once); type is the grammar (Persona = a face per glyph; realistic =
condensed type with a soft edge); shapes carry the style (scissor cuts, three colours; chrome only in metal
worlds); realistic means absence; measure, never guess; change the MEDIUM before polishing; show every round.
