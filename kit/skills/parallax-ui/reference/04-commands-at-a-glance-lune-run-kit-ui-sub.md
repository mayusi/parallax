## Commands at a glance (`lune run kit ui <sub>`; every one ends with summary + next_action)

| Stage | Command | Does |
|---|---|---|
| refs | `refs <id> "<game>" "<words>" [--wiki <fandom sub>] [--steam <app>] [--keep 1,4]` | real stills by API into refs/<id>/candidates → keep the good ones |
| refs | `refs ... --rank "<what>"` · `read rank <folder> "<what>"` | SigLIP ranks the candidates by "<what> is in it" (a HUD still beats a scenery shot); collages lose 3 and each HALF is ranked as its own candidate (`<name>_L` / `_R`), a menu page is a negative unless asked, and a request that names a genre (fighting / shooter) drops other-genre frames by 2 |
| refs | `read <still> [--find "<what you see>"] [--crops] [--draft <Screen> --identity <id>]` | reference UNDERSTANDING: where the interface is (192 px heat + edge strips + 432 px logo pass + a menu's repeated cards / list rows), each box snapped to its borders, named by GENRE + shape + place (minimap, ammo block, P1 health bar, title logo...) and by the WORDS in it (local OCR: RapidOCR, vetted — TENSION, LEGENDARY, a timer's digits) + its colours -> `<still>.read.json`; `--find` boxes what you DESCRIBE (grouped SigLIP windows: Hollow Knight's soul vessel + masks found top-left); `--crops` saves each piece as its own picture at the still's resolution (`<still>_pieces/<Role>.png`, the input of `trace` / `ink --from`); `--draft` writes a STARTING screen with the reference's layout (placeholders named by job, tied to their nearest edge) |
| refs | `read motion <clip.gif\|mp4> [--fps 30] [--pieces <still>.read.json]` | MOTION understanding: the clip's beats (start / peak / end s), cuts and holds -> `<clip>.motion.json` + a timing strip; copy real timing into a reel (Persona's baton touch: four cuts every ~0.37 s, then a 0.3 s hold); `--pieces` = beats PER PIECE (which one moved when: StriveCombo's bar showed all 5 hits) |
| refs | `read type <crop>` | TYPE understanding: the lettering in a crop measured (cap height, stroke weight, slant, tracking, fill, outline) -> the `letter` flags to start from (`--shear` = a real italic; `--lean` only rotates the word) |
| refs | `read prior <genre> [--draft <Screen> --identity <id>]` | LAYOUT KNOWLEDGE across games: every read of that genre aggregated — each named piece's median box, its spread, in how many games (fighting, from Tekken 8 / DBFZ / Strive: health bars top at y 50-111, super gauges bottom) -> `assets/ui/priors/<genre>.json`; `--draft` lays a new screen out by it |
| refs | `refs <id> --index` · `--tag <file>=hud\|menu\|art\|world[:<screen>]` · `--waive "<owner words>"` | the stills AS DATA: each still's size + the screen type it shows in `refs/<folder>/refs.json` (kit/ui/refsdb.py; `--keep ... --type hud` tags kept ones); the plan's refs lock reads it — ≥ 2 stills of the screen's `kind` (+ `screen_type`) at ≥ 1080p, or the owner's quoted waiver |
| refs | `measure <still>` → `identity <id> --from refs` | layout + palette measured by script → an identity DRAFT with evidence lines |
| pieces | `ink <id>/<p> --from <picture> [--mode ink\|cel\|icon]` | a REAL picture → halftone ink / flat cel (palette own\|identity\|mono) / HUD icon (outline + lines + halo) |
| pieces | `letter <id>/<p> --text ... [--style persona]` or `"lettering"` on a node | display lettering (persona: a face per glyph); the words step bakes `"lettering"` nodes automatically. Flat style: `--inline <colour>` (a highlight line inside the fill), `--arc <deg>` (a true arch; − sags), `--bounce <em>` (glyphs hop), `--drip <em>` (ink drips; `--drip-phase` grows them as a flipbook), `--shear` (italic), `--glow <colour> [--glow-px 0.12] [--glow-alpha 0.7]` (a soft halo: a death word, a sign); an upright face is always picked over its Italic twin |
| pieces | `letter <id>/<set> --text 8 --glyphs "0123456789" [same flags]` | a DIGIT SET: each glyph alone on one baseline in one monospace cell (`<set>_<code>.png` + `<set>.glyphs.json` with the `aspect`); a `"type": "number"` node composes it (ASCII only) |
| pieces | `icon find "<words>"` · `icon make <id>/<p> --icon <name> [--fill] [--ink] [--outline] [--glow]` | a FREE icon (game-icons.net, 4,239 SVGs, CC BY 3.0, vetted) made a crisp styled piece in the identity's colours; its credit goes into PROVENANCE by itself; 3D: `spin` it |
| pieces | `smear <id>/<p> --from <picture> [--angle] [--length] [--tint] [--echoes] [--split]` | a real picture's own pixels dragged into a banded speed trail + echo frames (a smear card, a dash); `--split` = the figure alone, to break a frame |
| pieces | `spin <id>/<p> [--material gold\|chrome\|silver\|enamel] [--motion spin\|sway] [--frames 24] [--depth] [--bevel] [--alpha] [--exposure]` | a flat piece -> a bevelled 3D mesh with its art on the face, as a flipbook (`<p>_spin_fNNN`, play with a reel `art` track) + sheet + FBX; a card wants `--depth 0.035 --bevel 0.008 --exposure -0.8`; `--motion flip --back <id>/<p>` = a card turning from its back to its face, once (a reveal); `--motion land` = a medal spinning down to rest face-on, once; `--edge enamel|#rrggbb` = the sides + bevel in their own material (a gold face on a dark rim); `--motion-file <json>` = a motion of your own as keyed curves ({"y": [[t, deg], ...]}); `--gloss 0.05` = a matte printed face (0.5 a lacquered card); `--depth-relief 0.22` = a SCULPTED front (a grid raised by Depth Anything V2: a figure gains real volume; best on coloured renders, not flat emblems); `--relief 3` = a STEPPED relief (brighter levels raised in steps: a stamped emblem); `--frames 0` = the FBX only (VFX / 3D can call it); `--cards K` = K depth-sliced PARALLAX cards (PNGs + one FBX of K quads) for VFX |
| pieces | `render <id>/<p>` · `trace <id>/<p> --from <still>` · `gauge <Screen>` | Blender chrome / a traced replica / an ornate gauge from anchors; render items: text, ring, gauge, gem, `dial` (a lit arc in a bezel: `bezel {base, roughness, metallic, coat}`, `bezel_width`, `step`, `glare_alpha`, a matte face) — one merged `<p>.anchors.json` (rows, dial / dials, gem) |
| pieces | `routes <Screen>` (python kit/ui/routes.py) | every picture the screen shows by its PIECE ROUTE (trace / letter / ink / render / smear golden; digits / spin / icon ok; plate / concept / drawn / typed caution; unknown graveyard) from its sidecar or PROVENANCE row — the table and the counts are `library/ui/ROUTES.md` |
| pieces | `find "<words>"` | the proven-piece bank across identities and the library — look before generating |
| build | `kit ui [--motion]` · `plan <Screen>` | compile + gates + previews (inherited rotation, at.scale) · the stage board: SEVEN LOCKED STAGES (refs → identity → pieces → assemble → look → judge → promote); a stage after the first unfinished one is LOCKED (its checks shown, no commands); ≤ 5 commands per stage; the pieces stage names every piece's route, wants ≥ 1 golden-route piece and a hero piece that is not typed |
| look | `look <Screen> "<seen>"` · `reel <Screen>` | record what you saw · gameplay motion from `<Screen>.reel.json` as a GIF + strip, with a MOTION CRITIC (`<Screen>.critic.json`: linear movement, entrances slower than ~0.6 s, siblings sliding in on one frame, a hero without an overshoot, no still moment to read — from Material 3's motion tokens + animation practice; advice, a deliberate slam may break a rule) |
| judge | `judge <Screen>` → two fresh judges → `--record` · `judge <Screen> --owner <score> "<words>"` | median + agreed gaps · the owner's verdict, kept as an anchor for every later packet |
| ship | `booth <Screen>` (Studio) · `bundle <Screen>` · `kit promote screen <Screen>` | the engine capture · a Studio build script · into the example library (with art, refs, gauge, reel) |

**In the engine** (Studio open; the MCP's `execute_luau`, datamodel Edit; Studio is shared — both remove what they build):
- the booth: `lune run kit ui booth <Screen> [--moments 0,0.3,0.8,1.6,3] [--job <reel job.json>]` → its steps (the shared
  capture bridge, no network): `python kit/vfx/capture.py studio ...` in the background, then `build/ui/booth/<Screen>.studio.luau`
  through Studio (execute_luau, Edit, KitPlaytestScratch), its answer line saved as `<Screen>.result.json` → LOOK at
  `build/ui/booth/<Screen>_engine.png`. The screen is the scratch place's OWN copy (rebuild the place after compiling:
  `lune run kit playtest place`; a stale one is named in the answer). The booth preloads the screen's art (`Ui.preload`) like
  the game's client does; a freshly uploaded asset can still be "being generated" by Roblox for a few minutes.
- the runtime playtest: `python kit/tools/studio_capture.py snippet ui_playtest --out build/ui/playtest/<Screen> --set
  screen=<Screen> --set bar=<bar path> --set text=<label path>`, run its `.studio.luau` in Studio → it RETURNS a JSON report (Ui.bar fill + ghost, Ui.text, Ui.number, Ui.flipbook, Ui.preload asserted on the
  engine's own instances); keep it as `assets/ui/<Screen>.playtest.json` (Arcade5Health: 9/9, 2026-10-16).
- the owner's one-key rating: `python kit/ui/rate.py <Screen>` → open http://127.0.0.1:47813/ (the engine capture, the
  preview, the verifier's pairs and the reel comparison side by side) → one key 0-9 (or 10) + optional words records
  `kit verdict screen <Screen> <n> "<words>"`; the server answers this machine only and stops after one rating.
