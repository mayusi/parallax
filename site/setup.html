Getting started

Setup

This guide takes a Windows 10 or 11 machine to a working Parallax project. It covers the toolchain, the kit, Roblox Studio, your AI client and a first run. Every step has the command, the check that proves it worked and what to do if it fails.

Hand this to your AI

If you want your AI agent to run setup for you, copy the prompt below, fill in the two blanks and paste it into your client.

Set up Parallax for me. Follow SETUP.md from https://github.com/mayusi/parallax step by step.
My game folder: <C:\path\to\MyGame>.  My AI client: <Claude Code | Cursor | VS Code | Gemini CLI | Codex | ...>.
Run every check and compare it with the expected result. Stop and ask me when a step needs me
(admin prompts, sign-ins, Roblox Studio settings). Never ask me for a password or an API key.

Your agent should follow these rules when it reads that prompt:

  • Do each step in order. Run its check and compare it with the expected output.
  • A failed check is not a next step. Follow the step's recovery notes, then run the check again. Never skip a step or continue past a failed check.
  • Stop and ask you when a step requires human action: an installer UAC prompt, signing in, Roblox Studio's own settings switches, or a choice that is yours (the game folder, your AI client, which optional lanes to install).
  • Never ask for, type or store a password, token or API key.
  • Report at the end using the final check's summary: lines.

Every Parallax command ends with summary: and next_action:. When a check fails, its next_action: is usually the fix.

Installation steps

  1. 1
    Base toolsInstall Git, Python 3.11, Node.js and ffmpeg.

    Skip any tool you already have. Run this in PowerShell:

    winget install --id Git.Git -e
winget install --id Python.Python.3.11 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Gyan.FFmpeg -e

    Open a new terminal (installers change PATH only for new terminals), then install the Python packages:

    python -m pip install numpy scipy pillow matplotlib pytest

    Check

    git --version
python --version
node --version
ffmpeg -version
python -c "import numpy, scipy, PIL, matplotlib, pytest; print('python packages ok')"

    You should see a version line for each tool, Python 3.11.x, and python packages ok.

    If it fails — "not recognized": open a new terminal and try again. Still failing: install the tool from its own site (git-scm.com, python.org — tick "Add python.exe to PATH" — nodejs.org, ffmpeg.org) and open a new terminal. If python opens the Microsoft Store, turn off the "App execution aliases" for python in Windows Settings.

  2. 2
    RokitInstall Rokit, the Roblox toolchain manager that pins exact versions. 
    Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression

    Open a new terminal.

    Check — rokit --version prints a version.

    If it fails — download rokit.exe from the latest release page at github.com/rojo-rbx/rokit and run .\rokit.exe self-install in that folder, then open a new terminal.

  3. 3
    Get ParallaxClone the kit and install its toolchain and packages.

    Choose a folder for the kit (your games live in their own folders next to it):

    git clone https://github.com/mayusi/parallax.git
cd parallax
rokit install
wally install

    rokit install may ask once whether you trust each tool. They are the six tools in rokit.toml from their official authors — answer yes. An AI agent cannot answer an interactive trust prompt; ask the person to run rokit install once in their own terminal.

    Check

    lune run parallax version

    You should see summary: kit 3.1.0 (or newer).

    If it fails — lune not recognized: open a new terminal (Rokit adds its folder to PATH). wally install fails: check your internet connection and run it again.

  4. 4
    Check the toolchainRun doctor to confirm Tier 0 is complete and see what higher tiers need. 
    lune run parallax doctor

    Check — every Tier 0 tool (Rokit's six, Python and its packages, Node.js, ffmpeg, the Wally packages) is found, and the output includes a machine tier: N line (then ends with summary: and next_action:). Missing optional tools are listed with the lane each one blocks and how to get it — that is fine until you use that lane.

    If it fails — install what it names, open a new terminal, and run doctor again.

  5. 5
    Choose your hardware tierInstall optional tools and AI models based on what your machine supports and which lanes you need.

    Parallax runs on any PC and grows with your hardware. Steps 1–4 already give you Tier 0. Go as far up as your machine and your lanes need.

    See the Hardware and models page for the full tier table, the AI models each tier adds and what each one unlocks.

    Tier 1 — DCC and CAD (3D, bakes, animation, worlds). Any CPU. Install Blender 5.2 LTS from blender.org into its default folder (C:\Program Files\Blender Foundation\); Parallax finds the newest version there. If you install it somewhere else, set a BLENDER environment variable to the full path of blender.exe. Then:

    lune run parallax tools setup kit-python
lune run parallax tools setup cad
lune run parallax tools setup mitsuba

    The vision setup commands below download model weights only. Each model also needs a runtime, which the Hardware and models page names tier by tier.

    Tier 2 — Light vision core (cut-outs, depth, similarity; ~2.4 GB). CPU or a 4 GB GPU. These models run in the kit's own Python, which needs PyTorch, transformers and safetensors. No Parallax command installs them: doctor's "torch (vision)" row says pip torch. Pick the PyTorch build for your OS and GPU with the selector at pytorch.org, install transformers and safetensors with pip, then:

    lune run parallax vision setup

    Tier 3 — Local VLM and diffusion (~44.6 GB more). An NVIDIA GPU with 12 GB VRAM and 16 GB RAM. SAM 3 (a gated model) is included in this tier; it requires you to request access on Hugging Face with your own account and set HF_TOKEN in your environment — without it the tier skips SAM 3 and the free SAM 2.1 masks stand in:

    lune run parallax vision setup --tier vision

    Qwen3-VL runs in the kit's own Python. The other Tier 3 models need two environments that this command does not create: the diffusers environment (SDXL, FLUX.2, DiffusionLight) and the TRELLIS.2 environment (Depth Anything 3, MoGe-2, Marigold-IID, SAM 3). Set both up from kit/gen/README.md; the TRELLIS.2 environment is compiled with CUDA 13 and MSVC 2022.

    Tier 4 — Full 3D generation (~24.5 GB more of models, plus the generator environments). CUDA 13, 12–16+ GB VRAM, 32 GB RAM, MSVC 2022. qwen-image-edit runs in sd-cpp, a native Windows program this command downloads. After the models, follow kit/gen/README.md for the generator environments:

    lune run parallax vision setup --tier gen

    Each Tier 4 generator has its own licence; some restrict territories or uses. Read its VETLOG.md row before installing. Everything runs on your machine; nothing is sent to a cloud service.

    To list all models with their tier and size before downloading:

    lune run parallax vision setup --list

    Check — lune run parallax doctor prints machine tier: N and, below Tier 4, exactly what the next tier needs. lune run parallax vision doctor runs the core models on a probe image and prints the torch version and GPU it found.

  6. 6
    Roblox Studio and its MCP serveryou do thisEnable the Studio MCP server so the kit can drive playtests and uploads.

    Roblox Studio has a built-in MCP server. Parallax uses it to drive playtests, look at the game in the engine and upload assets through Open Cloud with your own Studio login — no API key needed.

    1. Install Roblox Studio from create.roblox.com and sign in. You do this — not your AI agent.
    2. Open a place from a published game. Open Cloud permissions are saved per game; a local, unpublished place cannot use them.
    3. Turn the MCP server on: open Assistant, click … → Manage MCP Servers, and turn on Enable Studio as MCP server. You do this — the AI agent must not change these switches.
    4. Add the Roblox Studio MCP to your AI client. Assistant's settings offer a quick connect for Claude Code, Codex CLI, Claude Desktop, Cursor, Gemini CLI and VS Code. For any other client, add this entry (Windows): 
      {
  "mcpServers": {
    "Roblox_Studio": {
      "command": "cmd.exe",
      "args": ["/c", "%LOCALAPPDATA%\\Roblox\\mcp.bat"]
    }
  }
}
      On macOS the command is /Applications/RobloxStudio.app/Contents/MacOS/StudioMCP.
    5. Allow uploads — you do this: click MCP in Studio's bottom-right corner → MCP Permissions. Under Publish and manage assets, allow asset:read and asset:write (and asset-permissions:write if audio should be granted to your experience). Approve your game project's build folder as an upload folder. Changes apply to the client's next request.

    Check — Assistant → … → Manage MCP Servers shows a green indicator, and your AI client lists the Roblox Studio tools (for example list_roblox_studios).

    If it fails — restart Studio and the AI client; check the path and the JSON syntax of the config. Roblox's own guides: Connect to the Studio MCP server and Use Open Cloud with the Studio MCP server.

  7. 7
    Make your game projectInstall the kit into a new game folder.

    From the kit's folder, point install at your game folder (it is created if it does not exist; an existing Rojo project keeps its files):

    lune run parallax install ..\MyGame
cd ..\MyGame
git add -A
git commit -m "Start from Parallax (cross)"

    install copies the kit (kit/) and its in-game runtime (src/kit/), starter content, a work board (board/ with BRIEF.md) and the git hooks, then runs rokit install, wally install and git init. It writes no AI-client files — the next step adds the one you use.

    The word cross in the commit message tells the lane fence — the git hook that keeps each commit to one department — that this commit spans every department on purpose.

    Check

    lune run parallax status

    You should see the board's summary and a next_action:.

    If it fails — if install reports that rokit install or wally install failed, run them in the game folder yourself, then lune run parallax doctor.

  8. 8

    Run this in the game folder:

    lune run parallax connect <client>

    Use your client's name from the table below.

    lune run parallax connect claude

    Writes .mcp.json (the MCP server entry) and .claude/settings.json (the enforcement guard hooks). Restart Claude Code in the game folder afterwards.

    Config file
    .mcp.json in the game folder
    Guard hooks
    .claude/settings.json — PreToolUse, PostToolUse and Stop hooks that run kit/scripts/parallax_guard.py

    Writes .cursor/mcp.json in the game folder. Restart Cursor in the game folder afterwards.

    Config file
    .cursor/mcp.json in the game folder
    Guard hooks
    none for Cursor
    lune run parallax connect vscode

    Writes .vscode/mcp.json in the game folder. Restart VS Code in the game folder afterwards.

    Config file
    .vscode/mcp.json in the game folder
    Guard hooks
    none for VS Code
    lune run parallax connect gemini

    Writes .gemini/settings.json (the MCP entry and the enforcement guard hooks). Restart Gemini CLI in the game folder afterwards.

    Config file
    .gemini/settings.json in the game folder
    Guard hooks
    .gemini/settings.json — BeforeTool and AfterTool hooks that run kit/scripts/parallax_guard.py
    lune run parallax connect roo

    Writes .roo/mcp.json in the game folder. Restart Roo Code in the game folder afterwards.

    Config file
    .roo/mcp.json in the game folder
    Guard hooks
    none for Roo Code
    lune run parallax connect opencode

    Writes opencode.json in the game folder. Restart OpenCode in the game folder afterwards.

    Config file

    Guard hooks
    none for OpenCode
    lune run parallax connect codex

    Prints a block to paste into ~/.codex/config.toml (the kit's global config path for Codex CLI). The block carries this project's absolute path.

    Config file

    Guard hooks
    none for Codex CLI
    lune run parallax connect windsurf

    Prints a block to paste into ~/.codeium/windsurf/mcp_config.json. The block carries this project's absolute path.

    Config file
    ~/.codeium/windsurf/mcp_config.json (global; you paste it)
    Guard hooks
    none for Windsurf
    lune run parallax connect cline

    Prints a block for Cline's MCP settings (MCP Servers → Configure MCP Servers). The block carries this project's absolute path.

    Config file
    Cline's MCP settings (global; you paste it)
    Guard hooks
    none for Cline
    lune run parallax connect claude-desktop

    Prints a block for claude_desktop_config.json. On Windows: %APPDATA%/Claude/claude_desktop_config.json. On macOS: ~/Library/Application Support/Claude/claude_desktop_config.json.

    Config file
    claude_desktop_config.json (global; you paste it)
    Guard hooks
    none for Claude Desktop

    To connect several clients at once: lune run parallax connect claude,cursor. To remove an entry: lune run parallax connect <client> --remove.

    Check — lune run parallax connect (no arguments) lists your client as connected. Clients that print a block are not tracked — check them in the client. The client should show the tools parallax_start, parallax_status, parallax_skill and the others.

    If it fails — the client does not list the tools: make sure it was started in the game folder, that python works in a new terminal, and that you approved the server.

  9. 9
    First run and final checkAsk the board what it shows and run the three final checks.

    In your AI client, in the game folder:

    Call parallax_status and tell me what the board says.

    Then fill in board/BRIEF.md (what the game is) and ask for the first piece, for example:

    Start the 3d lane: a mossy stone well for the village square.

    Final check — in the game folder:

    lune run parallax harness --check
lune run parallax doctor
lune run parallax verify

    harness --check says the git hooks and every connected client's config are in step. doctor shows no missing required tool. verify ends with summary: verify: all gates green. The first verify takes a while.

Uploading to Roblox

lune run parallax upload screens every new or changed file through a moderation gate (banned words, blood) and writes an upload plan at build/upload_plan.json with the exact Roblox Studio MCP call for each file.

Your agent then, for each file:

  1. Calls open_cloud_invoke with that file's call from build/upload_plan.json (the studio_id comes from list_roblox_studios).
  2. Polls GET /assets/v1/operations/<operationId> with open_cloud_invoke until done is true.
  3. Records the returned id: lune run parallax upload --record <file> <assetId>.

lune run parallax upload --pending lists what is left; after the last one the kit recompiles the models and screens that use the new ids.

One-time setup

In the game's kit.config.json, set "upload": {"creator": "user:<your user id>", "universe": <experience id>}. Your user id is the number in your roblox.com profile URL; the universe is the experience that should play the audio.

Uploads are permanent

Open Cloud cannot delete uploaded assets. New images and sounds go through Roblox moderation: check status with lune run parallax upload --status.

For headless runs (CI, no Studio open): set ROBLOX_API_KEY in your environment and the kit uploads by itself — never paste a key into a chat or a file.

Updating

Inside your game folder:

lune run parallax upgrade --check
lune run parallax upgrade

--check compares the installed version (kit/UPSTREAM.json) with the latest release and writes nothing. upgrade refuses when you have edited the kit's own files (--force overrides) or have uncommitted changes (commit first, or pass --allow-dirty).

It downloads the release, checks its SHA-256 before unpacking, backs up the current kit, then updates in four zones: the kit's code is replaced (a file you added under kit/ stays); starter content and lessons are only added to; the knowledge vault is merged (your lessons, verdicts and rules are kept); your game's code and content are left alone. An error while replacing the kit's files restores the backup.

Pass --tag vX.Y.Z to pick a specific release; --from <tarball> (with its .sha256) installs a downloaded one. Restart your AI client afterwards if it says the MCP server changed.

After an update, lune run parallax harness refreshes the connected client's config and hooks. Commit the update on its own:

git add -A
git commit -m "Update Parallax (cross)"

In the kit's folder, pull the latest changes:

git pull

Then, from the kit's folder, push the update into a game:

lune run parallax update ..\MyGame

Or, from inside the game folder:

lune run parallax sync

A game holding a later kit version than the clone is refused — git pull the clone first, or pass --force to install the clone's kit anyway.

A game made with 3.0.0 has no upgrade command yet. Update it once from the local clone route (above), and upgrade works from then on.

After updating from 3.0.0, lune run parallax harness removes what that version wrote for every AI client (instruction blocks, rule files, skill copies and the kit's entry in each client's project MCP config), keeping anything you wrote yourself. The connected client that is running the update keeps its entry and hooks. Then connect any other client you use again:

lune run parallax connect <client>

Troubleshooting

ProblemFix
lune, rokit or python "not recognized"Open a new terminal; check the tool's install step.
rokit install stops at a trust promptAnswer yes for the tools in rokit.toml, or run it once in your own terminal.
A pipeline command says REFUSED / exits with 6Start the lane first: call parallax_start (or lune run parallax start <lane> --prompt "<the request>").
harness --check reports files out of stepRun lune run parallax harness, then commit what it changed if you share that client config.
The AI client does not show the parallax toolsStart the client in the game folder, approve the server, restart it.
The Studio MCP refuses a file or a scopeGo to MCP → MCP Permissions in Studio and approve the scope and the build folder.
rojo serve cannot connectOnly one project can serve on the port; stop the other one. Save a copy of the place before the first Connect — Rojo replaces what it manages.
The AI broke somethinggit restore . (uncommitted) or git revert (a commit). Edited kit files: lune run parallax sync restores them in a game installed from a local clone; in a game installed from a release, restore them with git checkout -- <the files>. lune run parallax status shows the last handoff and open tasks.

Uninstalling

A single game: run lune run parallax connect <client> --remove for each connected client (for a client that prints a block, it tells you which block to delete from that client's config). Then delete kit/, src/kit/ and parallax.luau, and remove the kit's two git hooks, commit-msg (the lane fence) and pre-commit (the commit gate). Your game's own files are untouched.

The kit itself: delete the kit's folder. Rokit's tools live in %USERPROFILE%\.rokit; the optional local models are in %USERPROFILE%\.cache\roblox-kit.
