Reference

Command reference

The commands listed by the kit's own help (lune run parallax help --all), grouped, with their syntax and purpose. The CLI is lune run parallax <command> [args]. Each command prints summary: and next_action: when it finishes. Older scripts may say lune run kit; that is the same CLI.

lune run parallax <command>
Note

Some commands take a literal --by owner or --owner flag. In those flags, "owner" means you: the person who runs the kit and approves the work. Syntax below is shortened in places; lune run parallax help --all prints every flag.

Note

Some lane sub-commands are documented in the lane's skill page rather than in the CLI help, for example the VFX simulations vfx cloth, soft, sand, hair, geonodes, water, liquid and points. Print a lane's skill with lune run parallax skill <lane>.

Exit codes

CodeMeaning
0Pass: the command succeeded.
1Lint: format check, Selene, types or the security audit failed.
2Tests: a Luau spec or a Python test failed.
3Build: the Rojo build or sourcemap failed.
4Playtest: an in-engine scenario failed.
5Toolchain: a required tool is missing.
6Content gate: a pipeline gate refused the content, or the Parallax gate refused the command.
7Usage: the command was called with invalid arguments.

The client guard hook is separate: it uses Claude Code's own codes, where 2 means blocked.
