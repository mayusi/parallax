Pipelines

Visual Effects

The VFX pipeline builds anime- and AAA-grade effects — ultimates, beams, slashes, explosions, auras, charge-ups, impacts — as version-3 layer-stack presets. Every effect starts from a measured breakdown of real footage, is approved three times (beat chart, animatic and style sheet), textured in Blender, and judged in a browser player as the effect alone.

Tier 1+ 3 approvals (chart, animatic, style sheet) 10 / 30 / 60 min clock 8 stages

At a glance

Makes
Version-3 layer-stack presets (assets/effects/<name>.json): ultimates, beam attacks, slashes, explosions, auras, charge-ups, impacts, environmental effects. Textures are made in Blender and uploaded separately.
Hardware
Tier 1 Blender 5.2 is required for texture recipes, simulation bakes (cloth, soft-body, sand, hair, Geometry Nodes, water, FLIP liquids), and renders.
Tier 2 BiRefNet for silhouette tracing from reference footage.
Tier 0 The browser player runs without a GPU.
Your approvals
Three stops: (1) the beat chart with one test frame of the key beat, before any full version is built; (2) the animatic (motion as flat shapes), before textures are applied; (3) the style sheet (every beat's look as a scene-vs-ours pair), after a recorded play.
Clock
Simple: 10 min · Complex: 30 min (default) · Hero: 60 min. The clock starts when you first run kit vfx <name> or kit vfx evolve <name>. Past budget, nothing new builds until you extend with your words.
Results land in
build/vfx/<name>.png (frames-over-time sheet), library/vfx/<kind>/<name>/ (every version, forever), build/textures/<key>.png (uploaded texture sheets).
Built and judged
In the browser player (kit vfx play <name>). Effects are never built or judged inside Roblox Studio. Studio is used only to prove engine facts.

The flow in one line

breakdown→ chart + test frame (you approve)→ method plan (104 methods, beat by beat)→ animatic (you approve motion)→ textures (Blender)→ preset (layer stack)→ browser player→ style sheet (you approve look)→ judge + evolve→ ship

Building an effect inside Roblox Studio is off this route and graveyard-flagged. The browser player is where effects are made and judged.

The stages

  1. 1
    Breakdown Measure the real source footage frame by frame: outline every beat, record every timing, trace every drawn shape.

    The breakdown is the foundation of every effect. Without real footage frames, there is nothing to build from — effects built from description text alone have scored 4 to 6; every 8-or-above effect was built from real frames.

    Step 1 — coarse pass (2 fps): kit vfx breakdown <set> --clip <file> --fps 2 samples the footage and builds a beat sheet in refs_measured/<set>.beats.md with measured colours per beat. Footage files are private and are never committed.

    Step 2 — timing (dense): kit vfx breakdown <set> --dense reads every shot of every beat at the clip's full frame rate. It captures how the light arrives, how long it holds, how it leaves, and where freeze frames or slow-motion marks fall. The output is refs_measured/<set>.timing.md and large frames in build/vfx/breakdown/<set>_dense/. The chart is timed from this, never from the coarse pass.

    Step 3 — trace: kit vfx trace <set> --beat N reads a beat's frames into outline curves and flat tones. The traces land in build/vfx/trace/<set>/; open each beat<k>_d<nn>.png to see the outline laid on its frame. A shot whose camera moves is refused unless you trace it with --track (the frames are stabilised first); kit vfx track <set> --beat N shows what the track follows. A flat background cannot be followed, and nothing is guessed.

    lune run parallax vfx breakdown <set> --clip <file> --fps 2
lune run parallax vfx breakdown <set> --dense
lune run parallax vfx track <set> --beat N   # what the camera track follows
lune run parallax vfx trace <set> --beat N [--track] [--box ...]
  2. 2
    Chart you approveDraw the beat chart with timing, one test frame of the key beat, and the palette — approved before any full version.

    kit vfx chart <set> draws every beat on the clock, marks hold and slow-motion frames, places the source frame beside each beat, and renders one test frame of the key beat. The palette (up to five colours) is derived from the footage measurements. The method plan is drawn under every beat in plain words.

    You must approve the chart — including the test frame — before any full version of the effect will build. Record your approval with kit vfx chart <set> --approve "..." --by owner. If the chart changes, it needs a new approval.

    Before showing the chart, kit vfx keyread <set> --effect <name> reads the test frame beside the key source frame on five dimensions (coverage, light, colour layers, detail, separate pieces). If it falls short on two or more, it is not ready to show.

    lune run parallax vfx chart <set>
lune run parallax vfx chart <set> --approve "<your words>" --by owner
  3. 2a
    Method plan Assign the kit's 104 effect-making methods beat by beat before the chart is shown.

    The method register is a list of 104 effect-making techniques that covers every approach the kit has built. Each method records its state (has, partly, missing, or not_roblox when Roblox has no place for it), how the kit does it, what tool it uses, and its proof — what in a preset shows the method is actually used (a layer kind, a key on that layer, a texture recipe).

    Before the beat chart is shown to you, every beat must have a method assignment. Use kit vfx methods --set <set> --beat N --use id,id to assign methods. Use --not id="<reason>" to leave one out with a reason. The chart draws the plan under each beat in your words; your approval locks the plan you saw.

    Two methods are asked for by a beat's own words: hand-drawn effects animation (hand_drawn; cues such as "flame", "fire", "slash", "smoke", "puff", "wisp", "tongue": traced, then inked) and fracture (fracture; cues such as "shatter", "crumble", "breaks apart"). Such a method must be used, or left out with a reason you have seen; otherwise the build is refused.

    lune run parallax vfx methods                      # the full 104-method list
lune run parallax vfx methods "drawn flame"         # one method: how, tool, proof
lune run parallax vfx methods --set <set>           # view plan beat by beat
lune run parallax vfx methods --set <set> --beat N --use id,id [--not id="<why>"]
    Note

    The method gate reads what a preset is made of, not how it looks. A planned method used badly still passes the gate. The gate also reads layer tags, not the actual clock — a layer tagged for beat 1 that runs on beat 2 is not caught.

  4. 2b
    Animatic you approveEvery beat as a flat shape at the chart's timing, recorded in the player, then shown beside the source in motion.

    The animatic proves the motion before any texture work. Each beat is represented as one flat shape (disc, ring, arc, bar, wall) at the chart's timing and the scene's measured share of the frame. Hit-stops are included.

    The result is recorded in the browser player and laid beside the source footage frame by frame (build/vfx/animatic/<set>_side.mp4). Watch the video; check that the motion reads correctly. The comparison frames are in build/vfx/dailies/<set>_animatic/.

    You must approve the animatic before textures are applied. The approval is recorded in the chart JSON and the preset build lock reads it.

    lune run parallax vfx animatic <set>
lune run parallax approve vfx <set> "<your words>" --by owner --stage animatic
  5. 3
    Textures Build surface looks with compositing sheets, trace and ink hand-drawn beats, and author Blender recipes for each material.

    Textures are made in two ways depending on what the beat needs.

    Surface looks (a skin, a ring, a glow, cracks, energy flows) are tried quickly as compositing sheets before any Blender render: kit vfx comp <key> --new ring|skin|blobs|branches|map. Edit the comp block (shape, panning noise, warp, erosion, the scene's colours in its ramp, halftone), re-run, and open the strip. A surface made of parts that behave differently — a steady core in a halo that tears — is authored as a node graph (--new graph).

    Hand-drawn sheets (beats the breakdown traced) are inked first: kit vfx ink <key> --from build/vfx/trace/<set>/beat<k>.json. Each cell is one drawing. Play the ink sheet in the browser before using it in a preset.

    Blender recipes (assets/textures/<key>.json, engine: fx) are authored for surfaces that need real Cycles renders — light bursts, volumetric fire, lit dust, energy flows, glowing cracks. The UV axis matters: beam textures are authored with their strip upright (Roblox runs the image's vertical axis along the beam). After a build, open build/textures/_fx_review.png before uploading.

    lune run parallax vfx comp <key> --new ring|skin|blobs|branches|map|shock|graph
lune run parallax vfx ink <key> --from build/vfx/trace/<set>/beat<k>.json
lune run parallax vfx <name>          # builds and renders changed textures
lune run parallax upload --only build/textures/<key>.png
  6. 4
    Preset Author the version-3 layer stack: mesh shells, flipbooks, particles, beams, cameras, lights, and simulations.

    The preset file (assets/effects/<name>.json, version 3) is a stack of layers. Each layer declares its kind (mesh, flipbook, particle emitter, beam, camera, light, ground) and its keys (texture, life, rate, colour, curve, beat tag). Variants and parts let you build an effect as a set of reusable components.

    Mesh shells (flame, tongue, spiral, bolt) are volume forms run by the kit's EditableMesh runtime. They give the anime silhouette that flat cards cannot.

    Simulations are baked in Blender and referenced as mesh sequences or flipbooks rather than simulated in the game. The pipeline supports cloth (kit vfx cloth), soft-body (kit vfx soft), sand (kit vfx sand), hair/fur (kit vfx hair), Geometry Nodes ripple/scatter (kit vfx geonodes), water height-fields (kit vfx water), and FLIP/PBF liquid flipbooks (kit vfx liquid).

    Fracture debris: objects that break into their own pieces are fractured before runtime (kit vfx fracture <name>), not thrown-rock particles. Pieces that should stay where they land use "rest": true on the layer. Debris pieces can also fall as real rigid bodies in the game ("floor": "world" on the debris layer).

    The validator runs on every build: caps, pro norms, legacy key checks, and the method gate all run before the build output is accepted.

    lune run parallax vfx <name>                     # build + validate preset
lune run parallax vfx fracture <name> --size w,d[,h] --pieces 14
lune run parallax vfx cloth <name> --pin top --wind 0,0,2
lune run parallax vfx soft <name> --drop 6 --soft 0.6
lune run parallax vfx sand <name> --mode slump --repose 34
lune run parallax vfx hair <name> --root cap --move toss
lune run parallax vfx geonodes <name> --recipe ripple|scatter
lune run parallax vfx water <name> --recipe drop|rain|slosh|dam|surge
lune run parallax vfx liquid <key> --solver flip --scene dam|drop|slosh
  7. 5
    Play Run the browser player with the kit's one-clock runtime; record and open the dailies sheet to compare against the source.

    The browser player (kit vfx play <name>) runs the effect at full frame rate with the kit's measured Roblox rules. This is where the effect is made and judged — not in Roblox Studio. Studio is used only to prove engine facts (see the limits section).

    The player uses a one-clock runtime (VfxStage) that supports hit-stop and slow motion. Freezing a stage also disables rate emitters, so the timing matches what the game will play. The player runs at the resolution the browser is set to and reads the render target directly on recording.

    --record saves a play to build/vfx/dailies/<name>/ and builds the dailies sheet: the source's consecutive frames above your effect at the same moments from the hit, two per picture. Open the key beat's frames. The light curves for each beat are on beat<k>_page.png.

    After recording, run kit checks run vfx <name> for the automatic quality checks (static level vs the library's range, impact-frame coverage).

    lune run parallax vfx play <name>
lune run parallax vfx play <name> --record
lune run parallax vfx dailies <name>    # re-run the dailies sheet from a stored recording
  8. 6 (removed)
    Studio booth Removed from the route.

    The Studio booth stage — building and capturing effects inside Roblox Studio with no animation around them — was removed from the route and placed in the graveyard. Studio is used only for proving engine facts (measuring how Roblox behaves). Effects are built and judged in the browser player only.

    Watch out

    Effects are made and judged as the effect alone, with nothing animated around it, in the browser player. Studio captures are off the route.

  9. 7
    Judge Scene frame vs render per beat, one difference named, one edit made; then four variants, you pick.

    kit vfx judge <name> runs the verifier: for each beat, the source frame and your render are placed side by side, one difference is named, and one edit is proposed.

    kit vfx evolve <name> builds four variants from the current state along different axes. You pick the one to continue. Your picks steer the axes of the next evolve round. An agent's pick is never counted — only yours.

    lune run parallax vfx judge <name>
lune run parallax vfx evolve <name>
lune run parallax verdict vfx <name> <0-10> "<your words>"
  10. 8
    Ship Vault check green, then promote to the library. Only on a verdict ≥ 7.

    kit vfx vault check must pass before shipping. It confirms every version is saved in library/vfx/ with its README, no file is missing or stale, and every earlier version is preserved. kit promote vfx <name> --about "..." adds the effect to the kit's example library — only on a verdict of 7 or above. Run kit lesson vfx to record any lessons from the session.

    lune run parallax vfx vault check
lune run parallax promote vfx <name> --about "<one line>"   # only on verdict ≥ 7
lune run parallax lesson vfx "<what you learned>"

Inputs and outputs

  • refs_measured/<set>.beats.md — beat sheet from the coarse breakdown.
  • refs_measured/<set>.timing.md — dense timing from the full-rate pass.
  • Source footage under assets/effects/refs/<set>/clip/ — private and git-ignored, never committed.
  • assets/effects/refs/<name>/ — reference stills per beat.
  • assets/effects/parts/ — reusable layer parts shared between effects.
  • assets/textures/<key>.json — Blender texture recipes (engine: fx).
  • assets/effects/<name>.json — the version-3 preset file.
  • build/vfx/<name>.png — frames-over-time sheet.
  • build/textures/<key>.png — rendered and uploaded texture sheets.
  • build/vfx/dailies/<name>/ — scene vs ours per beat (640 px per frame, two per picture).
  • build/vfx/breakdown/ — coarse and dense breakdown frames.
  • build/vfx/trace/<set>/ — outline traces per beat.
  • build/vfx/ink/ — inked drawing sheets.
  • library/vfx/<kind>/<name>/ — every version, forever, with README and verdicts.

Textures are uploaded via kit upload using the Studio MCP's open_cloud_invoke. The runtime modules live in ReplicatedStorage.kit:

  • VfxStage — plays a preset on the one-clock system (hit-stop, slow motion; freezing a stage disables rate emitters).
  • VfxCompose — manages beats, parts, and variants.
  • VfxMesh — runs EditableMesh shells (note: vertex alpha and TextureID alpha are ignored by Studio; mesh shells need a SurfaceAppearance for alpha).
  • VfxValidate3 — the runtime validator.

Preload textures before play with VfxStage.preload — an uploaded image is usable in Studio within seconds, but without preloading the first burst may be lost.

How it learns

Verdicts and the golden set

Every verdict is recorded. A verdict of 7 or above adds the effect to the golden set — the calibration baseline for future quality checks. A verdict of 3 or below puts its build route in the graveyard; every failed route becomes a gate that checks the same failure on the real piece (selftest fixtures in kit/selftest/vfx/owner_faults/). Re-run kit vfx director learn after every verdict so the director learns from it.

The library rule

Everything the VFX pipeline makes goes to library/vfx/ with a README. Nothing is ever deleted. Every earlier version is preserved under a new name. kit verify fails when anything made is missing or stale. To fix a stale library, run lune run parallax vfx vault.

Reuse mechanics before making new ones: kit vfx vault find "<words>", kit new vfx <name> --from <source>, and the parts in assets/effects/parts/. The look is never reused — only the mechanics.

The 104-method register

The method register (kit/vfx/methods.json) tracks 104 effect-making techniques. Each method has a state: has (the kit does it), partly, missing, or not_roblox (Roblox has no place for it; the register names a stand-in method). Proof of use is enforced per preset via the method gate.

The graveyard

Every failed route is now a gate on real pieces — not just a note. If the graveyard says a certain approach scored 0, that approach is refused on a new piece unless you approve an override. Known graveyard entries include: all-mesh auras, re-using last session's frames, building from description text alone, all-additive long-lived layers, untextured Neon ribbons seen edge-on, and smoke as many generic puff cards.

Evolve and gallery tuning

The evolve loop (kit vfx evolve <name>) builds four variants at once along different axes. Your picks steer the axes of the next round. An agent's pick is never counted; only your choices tune the direction. kit vfx director learn distils the vault into a director profile (kit/knowledge/vault/vfx/director.md) that shapes new briefs; re-run it after every verdict.

Engine facts

These facts were measured in Roblox Studio with the probe script (kit/vfx/facts.luau). Trust them over documentation.

FactWhat it means for building
EditableMesh vertex alpha ignoredA mesh shell's fadeIn, fadeOut, fadeSides, and erode are invisible in Studio. Only a SurfaceAppearance (ColorMap + AlphaMode Transparency) gives a mesh alpha. A dissolving mesh must use a baked flipbook, not erode.
EditableMesh TextureID alpha ignoredMesh shells draw their whole texture square, opaque. The browser player shows both vertex alpha and texture alpha; Studio does not. Player and Studio will disagree on mesh layers.
Particles do not draw EditableImage texturesAn EditableImage set as a particle texture is accepted but invisible. Upload real textures via kit upload.
Wobble cost (~0.25 ms per 697-vertex flame per frame)60 wobbling mesh layers = 14–17 ms, which is the whole frame budget. Keep wobbling layers few.
Beam texture axisThe image's vertical axis runs along the beam, horizontal across the width. Author beam textures with strips upright.
FaceCamera = false on a BeamMakes the beam a one-sided wall. Use plane: "up" to draw both faces.
Additive layers add up near a beamMultiple additive layers (glows, curtain, waves, halo, bloom) go flat white near the beam. Keep the sprites that ride a beam few and small; judge from the nearest camera.
Studio ticks ~20 Hz when unfocusedAffects recordings. The booth freeze compensates by freezing on exact times so captured frames stay correct.
ParticleEmitter with TimeScale 0 still emitsSetting TimeScale to 0 does not stop emission.

Known limits

Known limit

Water does not break or spray yet. The water pipeline (kit vfx water) supports drops, rain, sloshing, dams, and surges, but no breakaway spray.

Known limit

Liquids are flipbook slices only — a 2D slice with no depth, baked as a sheet. Liquid simulations (kit vfx liquid) are never matched to a real scene yet.

Known limit

The Mantaflow GPU smoke route is not yet proven end-to-end. Use kit/vfx/gpusim.py for simulated smoke/steam/dust, baked as a lit flipbook of one event at a time.

Known limit

Camera stabilisation fails on flat backgrounds. If the tracked background has no discernible features, the track will report failure and nothing is guessed.

Known limit

The method gate reads structure, not look quality. A planned method used badly (a hand-drawn texture placed at the wrong scale, an ink sheet played too fast) passes the gate. The gate also reads layer beat tags, not the actual clock position.

Known limit

Mesh dissolve must use a baked flipbook, never erode. The validator warns on erode; the method gate refuses it on new pieces.

A typical session

# 1. Start the lane with your request
lune run parallax start vfx --prompt "a lightning charge-up burst"

# 2. Create the effect
lune run parallax new vfx lightning_charge

# 3. Break down real footage of electrical discharges
lune run parallax vfx breakdown thunder_ref --clip assets/effects/refs/thunder_ref/clip/lightning.mp4 --fps 2
lune run parallax vfx breakdown thunder_ref --dense
lune run parallax vfx trace thunder_ref --beat 1
lune run parallax vfx trace thunder_ref --beat 2

# 4. Assign methods beat by beat
lune run parallax vfx methods --set thunder_ref
lune run parallax vfx methods --set thunder_ref --beat 1 --use lightning,branching,camera_shake
lune run parallax vfx methods --set thunder_ref --beat 2 --use hit_flash,impact_frame,bloom

# 5. Draw the chart with the method plan visible; check the test frame
lune run parallax vfx chart thunder_ref
# open build/vfx/charts/thunder_ref.png (the chart and its test frame)

# 6. Approve the chart (the test frame must look right first)
lune run parallax vfx chart thunder_ref --approve "test frame reads, timing matches" --by owner

# 7. Build and approve the animatic
lune run parallax vfx animatic thunder_ref
# watch build/vfx/animatic/thunder_ref_side.mp4
lune run parallax approve vfx thunder_ref "motion timing is right" --by owner --stage animatic

# 8. Build Blender texture recipes
# edit assets/textures/lightning_bolt.json (engine: fx, strip upright for beam)
lune run parallax vfx lightning_charge    # builds textures + validates preset

# 9. Run in the browser player and record
lune run parallax vfx play lightning_charge --record
# open build/vfx/dailies/lightning_charge/ — compare key beat frames against source

# 10. Style sheet and approval
lune run parallax vfx stylesheet lightning_charge
lune run parallax approve vfx lightning_charge "colours and timing match scene" --by owner --stage style

# 11. Judge and evolve
lune run parallax vfx judge lightning_charge
lune run parallax vfx evolve lightning_charge
# pick the best variant

# 12. Verdict and ship
lune run parallax verdict vfx lightning_charge 8 "burst reads, good weight on the hold"
lune run parallax vfx vault check
lune run parallax promote vfx lightning_charge --about "a lightning charge-up burst"
