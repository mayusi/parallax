Pipeline

Interfaces

The UI pipeline builds Roblox screens (HUDs, menus, shops, death screens, status sheets, and dialogs) that look like one game and no other. Every screen starts from an identity pack that pins tokens, type, shapes, motion rules, and bans before any art is made. Specs written in JSON are compiled to Rojo models, gated for readability and touch, previewed at phone, tablet, and desktop with real fonts, and driven in-game by the kit's Ui runtime.

Tier 0+ 2 approvals 10 / 30 / 60 min clock

At a glance

Makes
Rojo models (src/ui/<Name>.model.json), preview sheets at three viewports, motion strips, fuzz and localisation reports, saliency maps, identity style guides, and Studio capture scripts.
Hardware
Tier 0 Compile, gates, fuzz, localisation, saliency, fonts, the blind A/B page, and all text tools. No GPU is needed.
Tier 1 kit ui render (Blender Cycles) and kit ui spin (3D plate previews).
Tier 2 Reference ranking by similarity (SigLIP 2) and reference-based piece tracing.
Tier 3 Local VLM (Qwen3-VL) for identity screening. Without Tier 3 the kit sends your AI client a packet to review instead.
Your approvals
Two: your direction pick (stage 0) before any new identity is unlocked, and your verdict (scored 0–10 with words) in stage 6. Promotion to the library's examples needs a verdict of 7 or higher.
Clock
10 min for a simple screen, 30 min for a complex one, 60 min for a hero screen. Hero screens require kit approve first. Past the budget, no change to the screen can be built (the screen as it was can still be rebuilt and looked at); extend only on your words via kit clock ui <name> --extend <minutes> "<your words>".
Results land in
src/ui/ (Rojo models, never edit these), build/ui/ (previews, motion strips, fuzz and saliency outputs), library/ui/ (the permanent archive; kit verify fails if anything is missing).

The flow in one line

direction (you pick) → refs (≥ 2 stills at ≥ 1080p) → identity (tokens, type, motion, bans) → pieces (rendered / traced / inked / lettered) → assemble + compile → look (sheet + motion strip) → judge + verdict (you score) → promote (verdict ≥ 7)

The stages

  1. 0
    Direction you approveGenerate 3–5 original design directions; you pick one before any identity is written.

    Start every new visual look here, not at the identity. The command reads your words and produces 3–5 directions. Each direction names a world object, a verb, and a signature moment: a concrete visual idea, not a mood board. The kit then renders sketch frames onto a world shot so you can compare them side by side before committing.

    A new identity is locked until you pick a direction. Identities older than this rule are exempt.

    lune run parallax ui direct new MyGame --ask "a ruined city at dusk, tactical, clean readouts"
lune run parallax ui direct board   # view the sketch frames; pick one

    Produces: Direction spec files in assets/ui/directions/ and sketch frames in build/ui/directions/.

  2. 1
    ReferencesCollect ≥ 2 real stills of the exact screen type at ≥ 1080p, measured at 1:1.

    References are the ceiling, not inspiration. You need at least two real, full-resolution stills of the specific screen type you are building (a health bar, a menu, a death screen). Gallery contact sheets are not acceptable (they collapse at measurement). Measure each still at 1:1 and record everything in REFS.md.

    Every later stage is locked until this gate passes. The selftest fixture for the locked state is kit/selftest/ui/refs_too_small.

    lune run parallax ui refs MyTheme "<game>" "<words>"   # real stills into refs/MyTheme/candidates
lune run parallax ui measure <still>                    # layout + palette measured by script

    Produces: REFS.md entries for the screen type.

  3. 2
    IdentitySample tokens from the references and compile the identity pack: type trio, shapes, motion, bans, minimums.

    An identity pack is a JSON file at assets/ui/identities/<name>.json. It is built from your references by the kit ui identity command, which samples colour tokens, selects an Enum.Font trio, defines shape language and motion rules, and records bans and minimums for the screens that use it.

    Important: Roblox does not support custom TTF fonts. Every font in an identity is an Enum.Font value mapped to its Google Fonts family in kit/ui/fonts.json (each font file sha256-pinned in kit/ui/fonts.lock.json). There is no letter-spacing; glyph lists are the alternative.

    Every screen that names the identity in its spec compiles against its rules.

    lune run parallax ui identity MyTheme --from refs

    Produces: assets/ui/identities/MyTheme.json.

  4. 3
    PiecesMake every hero piece as rendered art, a trace, an ink, lettering, or a 3D spin; never use a tinted font glyph.

    A "piece" is any image asset a screen references. The pipeline enforces a medium rule: every hero piece must be one of the following, chosen before the build starts:

    • Render: a Blender Cycles render (Tier 1), read back by the kit to confirm it matches the spec.
    • Trace: a 1:1 crop of a real reference still, upscaled (Real-ESRGAN) and cut out (BiRefNet): the reference's own pixels are the art.
    • Ink: a real picture turned into halftone ink, flat cel (--mode cel, best on official 2D key art) or a HUD icon.
    • Letter: a lettered title or logotype drawn at the identity's lettering defaults.
    • Spin: a flat piece made into a bevelled 3D mesh with its art on the face, rendered as a turntable flipbook (plus the FBX).

    A typed font glyph with a tint is never acceptable as a hero piece. The one exception is a realistic HUD readout backed by "typed_hero_evidence" in the identity, citing the exact still that shows such a readout.

    If you change the medium of a piece (gaining a route, not losing one) the build refuses until you re-answer every lesson for the new route via kit answer ui <name> --reroute.

    lune run parallax ui render MyTheme/Icon
lune run parallax ui trace MyTheme/Logo --from <still> --box x,y,w,h
lune run parallax ui ink MyTheme/Card --from <picture> --mode cel
lune run parallax ui letter MyTheme/Title --text "..."
lune run parallax ui spin MyTheme/Medal

    Produces: Art files in assets/ui/art/<identity>/.

  5. 4
    AssembleCompile the JSON spec to a Rojo model; anchors and gates run automatically.

    The screen spec (assets/ui/<Name>.json) defines every node: type, text, layout, motion, state variants, pieces, and the identity it belongs to. The compiler resolves anchors via kit ui gauge: a "gauge" node provides a measured anchor point, and crest_width sets the global scale so child nodes scale in proportion. Children of a warped parent follow that parent's transform.

    The HUD size contract applies when a screen is driven partly by game code. Its contract file at assets/ui/huds/<Hud>.json records the code path, a block helper and resize function, and the measured size of each block from the approved reference round. kit ui hudsize (and kit verify) runs the HUD's own resize code at 1920×1080 and at desktop sizes and fails any block that falls below its floor times its reference size.

    All compile-time gates run here (see the Gates section). The model written to src/ui/<Name>.model.json is generated; never edit it by hand.

    lune run parallax ui MyScreen          # compile + all gates
lune run parallax ui MyScreen --motion  # compile + generate motion strip

    Produces: src/ui/<Name>.model.json (Rojo model), build/ui/<Name>.png (preview sheet).

  6. 5
    LookView the preview sheet and motion strip at all three viewports; record what you saw.

    The preview sheet renders the screen at phone, tablet, and desktop viewports using the actual Roblox Enum.Font values and their mapped Google Fonts families, not stand-ins. You must look at this sheet before the judge stage. No look record means no judge and no promotion.

    The motion strip (build/ui/<Name>.motion.png) shows every animated node's enter choreography as a horizontal filmstrip. If you have a reel spec (<Name>.reel.json), kit ui reel renders it to a GIF and an annotated strip showing bar drains, rolling counters, and state flips in timeline order.

    The motion critic (<Name>.critic.json) checks Material 3 timing rules automatically: ease-out on enter, ease-in on leave, entrances between 0.15 s and 0.6 s, staggered siblings, a 3–8% overshoot on the hero beat, and a still moment to read. It produces advice you review here.

    lune run parallax ui reel MyScreen                    # render the reel to GIF + strip
lune run parallax ui look MyScreen "bar drains clean, counter rolls at right speed"

    Produces: build/ui/<Name>.motion.png, build/ui/<Name>.reel.gif (if a reel spec exists), look record in the stage board.

  7. 6
    Judge you approveTwo fresh judges check for bugs; you give a verdict scored 0–10.

    Two independent judge passes run on the compiled screen, checking for bugs: wrong state shown, an empty flip face, a number node displaying "1 HITS", overlapping text. Each judge is fresh-context; it has not seen earlier stages.

    After the judge passes, the verifier produces a diff and one edit per piece. You then give a verdict with a score (0–10) and words. The score is recorded as kit verdict screen.

    A verdict is sha-keyed: it belongs to the build you judged. Never carry a verdict from one build onto a changed one.

    lune run parallax ui judge MyScreen
lune run parallax ui judge MyScreen --owner 8 "sharp, reads at a glance"

    Produces: Judge reports in build/judge/ui/<Name>/, verdict entry in the vault.

  8. 7
    Promote verdict ≥ 7 requiredUpload art to Roblox, archive everything to the library, and add the screen to the example library.

    Upload the art first: art that is not uploaded shows blank in-game; the runtime resolves asset IDs, not local file paths. After upload, kit ui vault check confirms the library entry is complete (renders, traces, anchors, refs, verdict, and reel if one was made). kit promote adds the screen to the example library as a reuse candidate, only on a verdict of 7 or higher.

    lune run parallax upload                   # upload all pending art
lune run parallax ui vault check           # confirm the library entry is complete
lune run parallax promote screen MyScreen --about "health bar with ghost drain and counter"

    Produces: Uploaded asset IDs in assets/ids.json, vault entry in library/ui/.

Inputs and outputs

  • assets/ui/identities/<name>.json: the identity pack: colour tokens, font trio, shape language, motion rules, bans, and minimums.
  • assets/ui/<Name>.json: the screen spec: node tree, types, text, layout, states, motion, and the identity it belongs to.
  • assets/ui/art/<identity>/: piece art files (renders, traces, inks, lettered images) referenced by name in the spec.
  • assets/ui/<Name>.reel.json: optional motion reel: tracks keying node properties over time, expanded from macros (flipbook, cycle, weave).
  • assets/ui/huds/<Hud>.json: HUD size contract for screens whose layout is driven by game code rather than by the spec alone.
  • Reference stills in REFS.md: ≥ 2 real stills at ≥ 1080p of the exact screen type, measured at 1:1.
  • src/ui/<Name>.model.json: the compiled Rojo model. Never edit this by hand; it is regenerated every build.
  • build/ui/<Name>.png: preview sheet at phone, tablet, and desktop viewports using real fonts.
  • build/ui/<Name>.motion.png: animated enter choreography as a horizontal filmstrip.
  • build/ui/<Name>.reel.gif and build/ui/<Name>.reel.png: reel render (if a reel spec exists).
  • build/ui/booth/<Name>.studio.luau: Studio capture script for the engine proof.
  • build/ui/fuzz/<Name>.json: fuzz report: overflow, squeeze, and off-screen issues with max-length text and large numbers.
  • build/ui/loc/<Name>.json: localisation report: pseudo-translation overflow and a list of lettered words that must have per-language versions.
  • build/judge/ui/<Name>/saliency/map.png: saliency heat map from 24 simulated first looks.
  • build/ui/guide/<identity>.html: identity style guide HTML page (from kit ui guide): tokens, type roles, shapes, motion, bans, and every screen wearing the identity.
  • library/ui/: permanent archive; kit verify fails if anything is missing or stale.

All screens compiled by this pipeline are driven client-side via ReplicatedStorage.kit.Ui. The UiMotion client script binds every kit screen automatically on load: hover, press, loops per node, per-viewport scale, and the enter choreography when a screen is enabled. You call the Ui API for state changes, data binding, and transitions.

Core Ui API (client only)

-- Fill a bar to 42%; the Ghost node drains late when health falls
Ui.bar(Ui.find("RpgHud", "Hud.Vitals.Hp"), 0.42)

-- Roll a counter to a new number (thousands separators are kept)
Ui.counter(Ui.find("RpgHud", "Hud.RpgBox.Souls"), 15210)

-- Set a "glyphs" label's text in the identity's own lettering
Ui.write(Ui.find("RiffNameplate", "Plate.Name"), player.DisplayName)

-- Enable a screen and play its enter choreography; false fades it out
Ui.show(playerGui.RpgDeath, true)

-- Transition from one screen to the next
Ui.transition(playerGui.RpgTitle, playerGui.RpgHud)

-- Apply a damped spring to any numeric, UDim2, Vector2, or Color3 property
-- frequency in Hz; damping 1 = critical, below 1 pops
Ui.spring(frame, "Position", UDim2.fromScale(0.5, 0.5), 4, 0.6)

-- Set a designed state on a control (nil returns to idle)
Ui.setState(Ui.find("SimShop", "Shop.Window.Grid.Pack1.Buy"), "locked")

-- Draw a Path2D vector line to 60% of its full length
Ui.path(Ui.find("RaceHud", "Hud.Dial.Boost"), 0.6)

-- Fire pooled UI particles from the identity's preset
Ui.burst(Ui.find("RushHud", "Hud.Callout"), "smash")

-- Attach a world-space nameplate to a part
Ui.attach(StarterGui.RiffNameplate, enemy.Head)

-- Pin a world marker to the edge of the screen when off-screen
Ui.track(Ui.find("Hud", "Hud.Goal"), workspace.Goal)

-- Push a queued toast ("good" uses the identity's success colour)
Ui.toast(Ui.find("Hud", "Hud.Toasts"), "Saved!", "good")

-- Apply a runtime material to a node (shimmer, ping, burn_in, split, flicker)
Ui.fx(node, "burn_in")

-- Honour a player's accessibility setting: stills split/flicker/ping (WCAG 2.3.1)
Ui.setReduceFlashing(true)

Combat Feedback Kit (UiCombat)

The UiCombat module provides rules for world markers, damage arcs, and streak ladders. Its rules are pure and tested separately in Lune. Access via Ui.waypoint, Ui.damageArc, Ui.streakLadder, and Ui.compare.

A marker whose margin is below half its own size (the pin hangs off the screen edge) fails the compile gate. A streak ladder with settings the runtime cannot honour also fails at compile time.

Player accessibility

The kit reads Roblox's native GuiService.ReducedMotionEnabled (2026). When set, enter animations become a short fade and loops stay still, satisfying WCAG 2.3.3. Ui.setReduceFlashing stills split, flicker, and ping effects on the caller's device. Ui.setHighContrast(true) gives every kit text a solid dark outline; false puts the design back.

Commands

# Start the lane (required before any other UI command)
lune run parallax start ui --prompt "a ruined city tactical HUD"

# Creative direction
lune run parallax ui direct new MyGame --ask "..."    # generate 3-5 directions
lune run parallax ui direct board                     # view sketch frames; pick one

# Identity
lune run parallax ui identity MyTheme --from refs     # build identity from references

# Piece making
lune run parallax ui render MyTheme/Icon              # Blender Cycles render (Tier 1)
lune run parallax ui trace MyTheme/Logo --from <still> --box x,y,w,h   # 1:1 crop, upscaled, cut out
lune run parallax ui ink MyTheme/Card --from <picture> --mode cel     # ink / cel / icon
lune run parallax ui letter MyTheme/Title --text "..."  # lettered title / logotype
lune run parallax ui spin MyTheme/Medal               # bevelled 3D mesh turntable

# Build + preview
lune run parallax ui MyScreen                         # compile + all gates
lune run parallax ui MyScreen --motion                # compile + motion strip
lune run parallax ui plan MyScreen                    # stage board (locked/unlocked state)
lune run parallax ui reel MyScreen                    # render reel to GIF + strip
lune run parallax ui hudsize                          # measure HUD code at screen sizes

# Quality checks
lune run parallax ui fuzz MyScreen                    # overflow check with max-length text
lune run parallax ui loc MyScreen                     # pseudo-translation / localisation
lune run parallax ui saliency MyScreen                # first-look saliency (need ≥ 85% on focus)
lune run parallax ui judge MyScreen                   # run two fresh judges for bugs
lune run parallax ui judge MyScreen --owner 8 "..."   # record your verdict (0-10 + words)
lune run parallax ui booth MyScreen                   # Studio engine capture

# Comparisons and regression
lune run parallax ui ab A B                           # blind A/B with recorded verdict
lune run parallax ui diff MyScreen                    # compare against golden (--approve locks it)
lune run parallax ui look MyScreen "..."              # record what you saw (required before judge)

# Style guide and library
lune run parallax ui guide MyTheme                    # write identity style guide HTML
lune run parallax ui vault find "health bar"          # search library before making
lune run parallax ui vault check                      # verify library completeness

# Upload and promote
lune run parallax upload                              # upload all pending art
lune run parallax promote screen MyScreen --about "..."

How it learns

Verdicts of 7 or higher go into the golden set. Verdicts of 3 or lower go into the graveyard, the lane's record of failed routes, which every new session sees when it starts, so the same mistake is not repeated.

Record a technique or trap at any time:

lune run parallax lesson ui "rolling counters need a mono face — proportional digits shift width"

After five or more new verdicts, kit vault distil ui produces an updated set of live rules from the verdict record. The golden regression floor is set by kit ui diff <Screen> --approve after a verdict of 7 or higher. Future builds that regress against the floor are flagged.

Start from proof: kit examples screen shows every screen you have rated, with its score. Known examples include an arcade title screen and menu (9.2 each), a gauge-style screen (8.5), a field HUD (8), and a smear-style card (8).

Tip

lune run parallax ui vault find "<words>" searches the library before you start. Reuse a proven piece from the library rather than making a new one from scratch.

Known limits

Known limit

Roblox caps TextSize at 100. There is no letter-spacing on text labels; use glyph lists as the alternative.

Known limit

Roblox does not support custom TTF fonts. Every font must be an Enum.Font value. The pipeline maps each one to its Google Fonts family for previews.

Known limit

SigLIP 2 cannot find faces in ink art. If a piece is an inked portrait, similarity search will not locate it by face.

Known limit

A derived screen can drop new nodes. Look at a derived screen's preview after you add nodes.

Known limit

Light direction across pieces is not measured yet. The pipeline does not enforce consistent light direction between separately made pieces on the same screen.

Known limit

Taste is yours: the kit's own judge rates screens lower than people do. Use it for catching bugs, not for quality scores.

A typical session

# 1. Start the lane with the request
lune run parallax start ui --prompt "a sword-fighting game HUD with health, stamina, and an ability timer"

# 2. Check what is pending from the last session
lune run parallax ui plan SwordHud    # stage board; see which stage is open

# 3. Make sure you have direction and an identity
lune run parallax ui direct new SwordGame --ask "fast, grounded, no gloss; worn metal UI"
lune run parallax ui direct board     # view sketches; pick the one that fits

# 4. Build identity from two reference stills you measured at 1:1
lune run parallax ui identity SwordTheme --from refs

# 5. Make the hero piece (health icon) as a render
lune run parallax ui render SwordTheme/HealthIcon   # Blender Cycles; reads the picture back

# 6. Compile the full screen and check gates
lune run parallax ui SwordHud --motion   # compile + motion strip

# 7. Look at the preview sheet and strip — record what you saw
# (open build/ui/SwordHud.png and SwordHud.motion.png)
lune run parallax ui look SwordHud "health drain ghost works; ability timer reads at phone size"

# 8. Run fuzz and localisation checks before the judge
lune run parallax ui fuzz SwordHud
lune run parallax ui loc SwordHud

# 9. Judge and record your verdict
lune run parallax ui judge SwordHud
lune run parallax ui judge SwordHud --owner 8 "clean, reads fast, good weight on the icon"

# 10. Upload the art; promote only if the verdict is 7 or higher
lune run parallax upload
lune run parallax ui vault check
lune run parallax promote screen SwordHud --about "sword-fighting HUD with ghost drain and ability timer"

# 11. Hand off with what you did and what comes next
lune run parallax handoff "built SwordHud: identity, render, compile, verdict 8" \
  --lane ui --next "add the death screen" --as "kit"
